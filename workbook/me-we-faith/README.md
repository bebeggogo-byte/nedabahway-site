> 새 Claude 채팅에서 이 **크리스찬 버전** 워크지 웹앱을 이어서 작업할 때 먼저 읽으세요.
> 세속 원본의 인수인계는 `../me-we/README.md`를 참고. 이 문서는 신앙 버전의 **차이점** 중심입니다.

## 한 줄 요약

세속 `me-we` 워크지를 각색한 **크리스찬 버전**. 구조·인터랙션 로직은 동일하고, 콘텐츠 레이어만
신앙 버전(성경 구절·묵상/기도·신학적 재프레이밍)으로 바뀌었습니다. 단일 자기완결 HTML.

- **소스**: [`workbook/me-we-faith/index.html`](./index.html) (단일 파일, 빌드 없음)
- **라이브 주소**: <https://www.nedabah.org/workbook/me-we-faith/>
- **원본(세속)**: `workbook/me-we/index.html` — 로직·구조의 기준 원본. 둘은 독립적으로 유지.

## 세속 원본과의 핵심 차이

- **localStorage 키 네임스페이스**: `meweF_<이름>_<PIN>` / `meweF_remember` (원본은 `mewe_`).
  → 두 버전의 응답이 절대 섞이지 않음. 로직 수정 시 이 프리픽스 유지.
- **브랜드 팔레트**: teal/orange/노랑 → 코발트 `#1E40AF` · 세이지 `#8a9a7a` · 종이톤(`#f7f3ec`/`#fdfaf3`).
  브랜드 하드룰: 노란색 금지, 순백 배경 금지, 보라-파랑 SaaS 그라데이션 금지 (출처 `.moai/project/brand/visual-identity-v1.md`).
- **성경 인용은 Noto Serif KR**(`--ff-serif`), `.verse` / `.verse-ref` / `.verse-more`(details) 스타일.
- **묵상/기도 입력**: 17개 활동 섹션마다 `md<SectionId>` / `pray<SectionId>` 한 쌍.
  → `bindInputs()`의 `ids` 배열에 등록되어 자동 저장/복원되고, `buildReport()`의 "묵상과 기도" 블록으로 PDF 리포트에도 들어감.
- **신학적 재프레이밍**: 각 섹션이 both/and 톤("심리학이 관찰한 것을 성경은 이렇게 말한다").
  예: 강점→은사, 셀프리더십→청지기, 영향력의 원→하나님 주권과 내 몫, 동기→소명·자원함(nedavah), 안전감→은혜의 공동체.
- **정체성 앵커**: 네다바웨이 = 히브리어 nedavah(נְדָבָה), 자원하는 예물/마음(출애굽기 35). 로그인·헤더·리포트·푸터에 반영.

## 성경 인용 규칙 (중요)

- **임의 창작 절대 금지.** 인용문은 검증된 뱅크에서만 verbatim으로 사용.
- 현재 사용된 번역: **개역개정**(주 본문, 전 섹션) + **NIV**(플래그십 3곳: 고전 12:26, 골 3:23, 잠 16:9) + **원어**(nedavah, charisma).
- 참조만 하고 인용 안 한 구절(시 103:2, 출 20:8, 눅 16:10 등)은 **개역개정 원문 표기 없이** 참조+쉬운말 요약으로만.
- **미완(TODO)**: **새번역** 병기는 아직 없음 — 정확한 출처로 검증한 뒤 `.verse-more`에 추가할 것.
  개역개정 원문 검증이 필요하면 `magazine/<BOOK>/<장>/index.html`의 기존 본문을 참조.
- 참조 형식: `골로새서 3:23 · 개역개정` (또는 약칭 `골 3:23`).

## 배포 / CI (원본과 동일)

- GitHub Pages(`.github/workflows/pages-deploy.yml`), `main` push 시 자동 배포. `workbook/` 포함.
- **링크 전용(비색인)**: `sitemap.xml` / `public-pages.txt` 건드리지 말 것(funnel-qa 게이트 균형). HTML lint 대상 아님.
- 수정 → 브랜치 → PR → `main` 병합 → 배포. 라이브 확인은 핸드폰(샌드박스는 사이트 egress 403).
