## 워크숍 한 줄 요약

> **결과물은 조사의 끝이 아니라, 조사의 설계도다.**

3팀의 출발선이 달라 **투트랙**으로 설계했습니다.

| | 트랙 A — 게팀 | 트랙 B — 곶자왈팀 · 거문오름팀 |
|---|---|---|
| 상태 | 아카이빙 완료 (36쪽 필드가이드 초안) | 아카이빙 없음 |
| 오늘 할 일 | 아이디어 → **결정** | 정리 → **아이디어** |
| 워크지 시작점 | **S1부터** | **S0 재고조사부터** |
| 끝났을 때 | 판형·부수까지 확정된 사양서 | 보유 자료 목록 + 결과물 후보 |

두 트랙을 잇는 다리는 **게팀이 21번 반복해 쓴 카드 양식 1장**입니다.
'게'를 지우고 '식물'을 넣으면 곶자왈 카드, '지점'을 넣으면 거문오름 카드가 됩니다.

## 진행자가 놓치면 안 되는 3가지

1. **게팀을 "모범"으로 소개하지 마십시오.** "먼저 간 팀"으로만 소개하고, 대신 **사진 21장이 전부 비어 있다는 사실을 반드시 공개**하십시오. 이것이 나머지 두 팀의 시작 문턱을 낮추는 장치입니다.
2. **워크지는 손으로 쓰게 하십시오.** 노트북을 열면 검색을 시작하고 작성이 멈춥니다.
3. **시간이 밀리면 연결 구간(68–83분)이 아니라 백캐스팅(58–68분)을 줄이십시오.** 서로 발표하고 질문받는 시간이 이 워크숍의 성과를 만듭니다.

### 업로드 방법 (수동)

NotebookLM은 MCP 커넥터가 없고 공개 API도 없어 **자동 업로드가 불가능합니다.**
notebooklm.google.com → 새 노트북 → **소스 추가** → 마크다운 파일 드래그.

Google Drive 커넥터를 이 대화에서 활성화하면 파일을 Drive에 올려 두고
NotebookLM에서 **Drive에서 가져오기**로 불러오는 방식은 가능합니다.

### 인용 시 주의 — 신뢰도 등급

소스팩 수집 당시 **원문 직접 열람(WebFetch)이 프록시에서 전면 차단**되어,
모든 내용은 **검색 색인(제목·본문 스니펫)** 에서 나왔습니다. 각 문서 첫머리에 등급 규칙이 있습니다.

| 등급 | 의미 | 사용법 |
|---|---|---|
| `[T]` | 검색 결과 **페이지 제목**에 그대로 있음 | 발표에 인용 가능 |
| `[S]` | 검색엔진이 **본문에서 추출**한 내용 | "~로 알려져 있다" 수준으로 완충 |
| `[미확인]` | 추정·근거 부족 | **인용 금지** |

**숫자(기온·습도·종수·면적·정원)는 발표 전 원문 1회 재확인이 필수입니다.**
관측기간이나 조사주체가 바뀌면 값이 달라집니다.

## 각 팀에 즉시 전달할 주의사항

**게팀**
- 농게의 제주 서식 여부를 뒷받침하는 자료를 찾지 못했습니다. 대상종 목록에 넣기 전 확인이 필요합니다.
- 보호종 일시 채집·방생의 법적 허용 여부가 확인되지 않았습니다. 조사 전 행정기관에 서면 문의하십시오.

**곶자왈팀**
- 곶자왈 **면적 수치가 출처마다 다릅니다**(110㎢ / 106.0㎢ / 95.1㎢). 하나를 고르지 말고 **기준연도와 조사주체를 함께 밝히는 방식**으로 인용하십시오. 이 충돌 자체가 좋은 발표 소재입니다.
- Braun-Blanquet 피도 계급이 자료마다 단계 수가 다릅니다. **계급표를 먼저 확정해 기록지 첫 장에 고정**하지 않으면 데이터가 섞입니다.
- 멸종위기 Ⅰ급 제주고사리삼 등의 **정확 좌표는 공개 결과물에 싣지 마십시오**(도채 위험). 지대 수준까지만 표기합니다.

**거문오름팀**
- **이중 규제 지역입니다** — 세계자연유산 구역이자 국가지정 천연기념물. 토양 채취·말뚝·고정조사구 마킹은 사실상 불가로 전제하십시오.
- **탐방 예약제**이며 **매주 화요일(자연휴식의 날) 탐방 불가**입니다. 반복 관측 설계에서 화요일은 원천 배제하십시오.
- 1일 정원·회차 정보가 자료마다 충돌합니다. **세계자연유산센터에 직접 전화 확인**하는 것이 이 팀의 1순위 행동입니다.
- 12월 마감이라면 **11월 중순에 데이터를 마감**하는 일정이 안전합니다.
