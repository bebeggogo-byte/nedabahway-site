How We Design

네다바웨이의 교육은
이렇게 설계됩니다.

10년간 수백 번의 현장에서 배운 것은, "완성된 프로그램"을 파는 것이 아니라 고객의 상황·사람·목표에 맞게 핵심 요소를 분해하고 재조합하는 일이었습니다.

1
상황을 듣습니다
대상(연령·직급·상태), 현장(시간·공간·분위기), 기관의 진짜 필요 — 표준 제안서를 건네기 전에 먼저 질문부터 드립니다.
2
핵심 모듈을 분해합니다
기존 프로그램을 통째로 옮기지 않습니다. 진로·AI·팀성과·코칭·퍼실리테이션·기업가정신을 각각의 모듈 단위로 분해해 두었습니다.
3
상황에 맞게 배합합니다
한 모듈만 깊이 파기도, 서너 모듈을 엮어 한 회차로 만들기도 합니다. "자기이해 + AI 도구 + 실행 계획"처럼 — 고객의 목표에 필요한 비율로.
4
현장에서 다시 조율합니다
강의실의 분위기, 참여자 개개인의 상태를 쉬는 시간마다 확인하고 레벨을 맞춥니다. 설계도는 어디까지나 뼈대일 뿐입니다.

Design Recipes

학년별로
이렇게 배합합니다.

같은 모듈이라도 학년·발달 단계에 따라 전혀 다른 무게로 담깁니다. 초등학교 5·6학년부터 대학생·취업준비생까지, 현장에서 실제로 검증한 배합 8가지.

초등 5·6학년
RECIPE 01
초등 5·6학년 직업 가치관 — 일이라는 말의 첫인상
상황: 직업을 ‘돈벌이 도구’로 단편적으로 인식하기 시작하는 시기. 가치관 형성의 가장 빠른 진입점이며, 부모·미디어의 영향을 크게 받는다.
설계 포인트: 직업 카드 분류 게임 → 가치 단어 30종 매칭 → ‘내가 좋아하는 일 vs 잘하는 일 vs 도움이 되는 일’ 3원 그림. 가르치지 않고 발견하게 만든다.
BLEND M1 진로(가치관 도입) + M4 퍼실리테이션(놀이형)
중학생
RECIPE 02
중학생 진로교육 — 자기이해에서 직업탐색으로
상황: 자유학기제·자유학년제 시기. 강점·흥미·가치를 처음 명시화하는 단계. ‘무엇이 되고 싶은가’보다 ‘어떻게 살고 싶은가’를 먼저 묻는다.
설계 포인트: 8종 강점 진단 → NCS 직업 매칭 → 만다라트 1장 작성. 학생이 자기 언어로 한 문장 진로 선언을 남긴다.
BLEND M1 진로(메인) + M4 코칭
RECIPE 03
중학생 학습법 — 공부의 이유와 도구
상황: 시험·내신 압박이 본격화되는 시기. 공부 자체를 거부하는 학생도, 무작정 외우는 학생도 같은 자리에 있다. 동기와 메타인지가 동시에 필요하다.
설계 포인트: 학습 동기 자가진단 → 인지·메타인지·정의 3축 점검 → 1주 학습 일지 템플릿 + AI 학습 도구 활용 가이드 1장.
BLEND M1 진로(학습 동기) + M2 AI(학습 보조)
RECIPE 04
중학생 기업가정신 기초 — 작은 문제에서 시작
상황: 진로교육과 별도 트랙으로, ‘만들어 보는 경험’을 통해 자기 효능감을 형성하는 시기. 거창한 창업이 아니라 학교·동네의 작은 문제에서 출발한다.
설계 포인트: 일상 불편 30개 발견 → 한 가지 선택 → 5W1H 정리 → 종이 시제품 발표. ‘불편을 해결한 사람이 직업을 만든다’는 감각을 심는다.
BLEND M6 기업가정신(메인) + M4 퍼실리테이션
고등학생
RECIPE 05
고등학생 진로교육 심화 — 결정 근거를 만드는 작업
상황: 진학·취업·창업의 갈림길에서 결정의 근거가 약한 학생이 다수. 정보의 양보다 자기 판단 기준의 명료함이 부족하다.
설계 포인트: 자기이해 3차원(능력·성향·가치) → 직업 정보의 1차 출처 검증 → 결정 매트릭스 작성. 결과보다 ‘어떻게 결정했는가’를 글로 남긴다.
BLEND M1 진로(심화) + M4 코칭
RECIPE 06
고등학생 고교학점제 대응 — 과목 선택의 근거
상황: 2026년 학업성취율 요건 완화 이후, 과목 선택은 ‘학점 따기 쉬운 과목’으로 쏠릴 위험이 커졌다. 진로 좌표와 과목 선택을 연결하는 작업이 필요하다.
설계 포인트: 진로 좌표 1장 → 3개 후보 진로별 핵심 과목 매핑 → 1·2·3학년 선택 시뮬레이션 → 학교 진로상담 시 사용할 1쪽 자료 제작.
BLEND M1 진로(매핑) + M4 코칭(개별)
RECIPE 07
고등학생 기업가정신 심화 — 린 캔버스 1장 시뮬레이션
상황: 창업 동아리·진로 캠프에서 ‘아이디어는 나오는데 실행이 멈춘다’. 문제 검증·고객 인터뷰·MVP 개념을 학년 수준에서 익히게 한다.
설계 포인트: 문제-고객-가치-채널 4칸 작성 → 5명 인터뷰 설계 → 1주 후 결과 발표. ‘아이디어가 아니라 검증’이 핵심이라는 감각.
BLEND M6 기업가정신(린 캔버스) + M1 진로(자기이해)
RECIPE 08
고등학생 멘탈코칭·진로고민 1:1 코칭
상황: 진학·시험·관계 스트레스가 겹치면 진로 결정 자체가 멈춘다. 단체 강의로는 닿지 않는 영역. 1:1 코칭과 단기 멘탈 정리 도구가 같이 필요하다.
설계 포인트: 감정 그래프 1주 기록 → 핵심 스트레스 좌표화 → ICF 코칭 질문 카드 → 1주 실천계획 1장. 결정을 강요하지 않고 결정 가능한 상태를 회복한다.
BLEND M4 코칭(메인) + M5 5R(관계 회복)
대학생 · 취업준비생
RECIPE 09
대학생·취준생 자기소개서 — 자기이해 · 키워드 · 자기분석 기반 커스터마이징
상황: 템플릿 자기소개서가 통하지 않는 시대. 동일한 스펙·동일한 학과에서 합격이 갈리는 지점은 ‘이 회사·이 직무·이 사람을 위한 한 줄’이다.
설계 포인트:
① 자기이해 — 강점 8종 진단 + 인생 5장면 인터뷰
② 키워드 — 본인 진술에서 반복되는 동사·명사 20개 추출
③ 자기분석 — 직무 요구역량과 본인 키워드 매칭표 1장
④ 커스터마이징 — 회사·직무별 첫 문장 3종 + 스토리 라인 재배열
결과물 : 1쪽 자기분석 카드 + 회사별 자기소개서 골격 3종.
BLEND M1 진로(자기이해·심화) + M4 코칭(1:1) + M2 AI(키워드 추출 보조)

Approach

배합의 기준이 되는
7가지 원칙.

F3
먼저 듣는다
표준 제안서보다 먼저 기관의 상황과 대상의 상태를 묻습니다. 설계는 그다음입니다.
F2
모듈 단위로 분해
기존 프로그램을 통째로 옮기지 않습니다. 핵심을 쪼개고 필요에 맞게 재조립합니다.
F1
코칭 기반 설계
ICF·5R CTC·액션러닝 역량을 녹여, 질문과 발견 중심의 수업으로 구성합니다.
🤖
AI는 도구, 사람이 목적
AI로 시도의 문턱을 낮추되, 최종 판단과 의미는 사람이 만들도록 설계합니다.
✋
체험 50% 이상
강의 30% · 워크숍 50% · 성찰 20%. 듣는 교육이 아니라 하는 교육으로.
☕
쉬는 시간도 설계
쉬는 시간마다 참여자 한 명 한 명의 상태를 확인하고 레벨을 맞춥니다.
F4
교육 후 연결
1회성으로 끝나지 않는 교육. 사후 코칭·실천계획·결과보고서까지 연결 설계.
