How We Design

네다바웨이의 교육은
이렇게 설계됩니다.

10년간 수백 번의 현장에서 배운 것은, "완성된 프로그램"을 파는 것이 아니라 고객의 상황·사람·목표에 맞게 핵심 요소를 분해하고 재조합하는 일이었습니다.

1
상황을 듣습니다
대상(연령·직급·상태), 현장(시간·공간·분위기), 기관의 진짜 필요 — 표준 제안서를 건네기 전에 먼저 질문부터 드립니다.
2
핵심 모듈을 분해합니다
기존 프로그램을 통째로 옮기지 않습니다. 진로·AI·팀성과·코칭·퍼실리테이션·기업가정신을 각각의 모듈 단위로 분해해 두었습니다.
3
상황에 맞게 배합합니다
한 모듈만 깊이 파기도, 서너 모듈을 엮어 한 회차로 만들기도 합니다. "자기이해 + AI 도구 + 실행 계획"처럼 — 고객의 목표에 필요한 비율로.
4
현장에서 다시 조율합니다
강의실의 분위기, 참여자 개개인의 상태를 쉬는 시간마다 확인하고 레벨을 맞춥니다. 설계도는 어디까지나 뼈대일 뿐입니다.
Module Library

배합에 쓰이는
7가지 핵심 모듈

각 모듈은 단일 교육으로도, 조합 교육으로도 운영됩니다. 아래는 현재 준비된 모듈 라이브러리입니다.

M1
Module 01
진로·취업 역량
자기이해 기반 강점 발견, 자소서·면접, 1:1 코칭. 청소년·청년의 "나를 알고 선택하는 힘".
8종 강점 진단NCS 매칭만다라트
M2
Module 02
직업 가치관
‘무엇이 될까’ 이전에 ‘어떻게 살까’를 묻는다. 가치 카드 30종 · 인생 5장면 · 가치-직업 정렬 매트릭스.
가치 카드 30인생 5장면가치 충돌 시나리오
🤖
Module 03

도구가 아니라 좌표. 보고서·홍보물·기획안 흐름에 AI를 결합하고, 마지막 한 줄은 사람이 쓴다.
프롬프트 5요소출처 검증실무 흐름 결합

Module 06
소통·관계·리더십
5S 5단계 — See(보다·자기 위치) · Speak(말하다·방향) · Sense(느끼다·함께 듣기) · Steer(잡다·다음 결정) · Sustain(잇다·다시 시작). 네다바웨이 고유 프레임. 5개 학문 영역에서 동시 검증 — 교육공학(ADDIE·Merrill) · 국제코칭(ICF) · 리더십(SL2·Goleman) · 진로(Krumboltz·Savickas·Super) · 직업(Schein·Hall·Holland)을 5단계 동사로 묶었습니다. 강의·1on1·회의·진로 상담·직업 설계·가정 어디서나 같은 사이클로 작동합니다.
SeeSpeakSenseSteerSustain

학년별로
이렇게 배합합니다.

같은 모듈이라도 학년·발달 단계에 따라 다른 무게로 담깁니다. 초등 5·6학년부터 대학생·취준생까지, 현장에서 검증한 배합 9가지.

01초등 5·6

직업 가치관 — 일이라는 말의 첫인상

‘돈벌이’로만 보이기 시작하는 시기. 가치관 진입점.

직업 카드 분류 → 가치 단어 30종 → ‘좋아하는 일·잘하는 일·도움이 되는 일’ 3원 그림.

M1 진로M4 퍼실(놀이형)
02중학생

진로교육 — 자기이해 → 직업탐색

자유학기제. ‘어떻게 살고 싶은가’를 먼저 묻는 단계.

8종 강점 진단 → NCS 매칭 → 만다라트. 한 문장 진로 선언.

M1 진로M4 코칭
03중학생

학습법 — 공부의 이유와 도구

시험 압박 진입. 동기와 메타인지가 동시에 필요.

동기 자가진단 → 인지·메타인지·정의 3축 → 학습 일지 + AI 학습 도구.

M1 동기M2 AI
04중학생

기업가정신 기초 — 작은 문제에서 출발

학교·동네의 작은 불편에서 자기효능감을 형성한다.

일상 불편 30개 → 한 가지 선택 → 5W1H → 종이 시제품 발표.

M6 기업가M4 퍼실
05고등학생

진로교육 심화 — 결정 근거를 만든다

정보보다 판단 기준의 명료함이 부족한 단계.

자기이해 3차원 → 1차 출처 검증 → 결정 매트릭스 → ‘어떻게 결정했는가’를 글로.

M1 진로M4 코칭
06고등학생

고교학점제 대응 — 과목 선택의 근거

학업성취율 완화 이후 과목 쏠림 방지가 필요.

진로 좌표 1장 → 후보 진로별 핵심 과목 매핑 → 1·2·3학년 시뮬레이션.

M1 매핑M4 코칭
07고등학생

기업가정신 심화 — 린 캔버스 1장

‘아이디어는 나오는데 실행이 멈춘다’.

문제·고객·가치·채널 4칸 → 5명 인터뷰 → 1주 후 결과 발표. ‘검증’이 핵심.

M6 린 캔버스M1 자기이해
08고등학생

멘탈코칭·진로고민 1:1

스트레스 누적으로 결정 자체가 멈춘 학생.

감정 그래프 1주 → 스트레스 좌표화 → ICF 질문 카드 → 1주 실천계획.

M4 코칭M6 소통
09대학생·취준생

자기소개서 — 자기이해 · 키워드 · 자기분석 기반 커스터마이징

템플릿이 통하지 않는 시대. 같은 스펙에서 합격이 갈리는 지점은 ‘이 회사·이 직무·이 사람을 위한 한 줄’.

① 자기이해(8종 강점 + 인생 5장면) → ② 키워드(반복 동사·명사 20개 추출) → ③ 자기분석(요구역량 매칭표) → ④ 커스터마이징(회사·직무별 첫 문장 + 스토리 라인). 산출물 : 1쪽 자기분석 카드 + 회사별 골격 3종.

Approach

배합의 기준이 되는
7가지 원칙.

F3
먼저 듣는다
표준 제안서보다 먼저 기관의 상황과 대상의 상태를 묻습니다. 설계는 그다음입니다.
F2
모듈 단위로 분해
기존 프로그램을 통째로 옮기지 않습니다. 핵심을 쪼개고 필요에 맞게 재조립합니다.
F1
코칭 기반 설계
ICF·5S(See·Speak·Sense·Steer·Sustain) 5개 학문 영역(교육공학·코칭·리더십·진로·직업)·액션러닝 역량을 녹여, 질문과 발견 중심의 수업으로 구성합니다.
🤖
AI는 도구, 사람이 목적
AI로 시도의 문턱을 낮추되, 최종 판단과 의미는 사람이 만들도록 설계합니다.
✋
체험 50% 이상
강의 30% · 워크숍 50% · 성찰 20%. 듣는 교육이 아니라 하는 교육으로.
☕
쉬는 시간도 설계
쉬는 시간마다 참여자 한 명 한 명의 상태를 확인하고 레벨을 맞춥니다.
F4
교육 후 연결
1회성으로 끝나지 않는 교육. 사후 코칭·실천계획·결과보고서까지 연결 설계.
