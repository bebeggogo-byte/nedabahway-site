# 클래식FM 라디오 — 안드로이드 폰에 앱으로 설치하기

다운로드도, 파일 설치도 필요 없습니다. **크롬에서 한 번 "설치"만 누르면** 홈 화면에 앱 아이콘이 생기고, 그다음부터는 일반 앱처럼 씁니다.
업데이트는 자동입니다(앱을 껐다 켜면 최신 버전).

---

## 1) 설치 (30초)

1. 폰에서 **크롬(Chrome)** 을 열고 주소창에 입력
   ```
   nedabah.org/radio
   ```
2. 라디오 화면 아래쪽에 **[지금 설치]** 버튼이 보이면 그걸 누르세요.
   (안 보이면 → 오른쪽 위 **⋮ 메뉴 → "앱 설치"** 또는 **"홈 화면에 추가"**)
3. **설치** 확인 → 홈 화면에 **"클래식FM"** 아이콘이 생깁니다.

> 삼성 인터넷을 쓰신다면: 주소 입력 후 아래 **≡ 메뉴 → "현재 페이지 추가" → "홈 화면"** 입니다.

## 2) 사용

- 홈 화면의 **클래식FM** 아이콘을 누르면 바로 라디오가 켜집니다(자동 재생, 안 되면 화면 아무 데나 한 번 터치).
- **화면을 잠가도 계속 나옵니다.** 잠금화면·알림창·이어폰·차량 버튼으로 **일시정지/재생** 됩니다.
- 통화가 오면 멈췄다가, 통화가 끝나면 스스로 다시 나옵니다. 잠깐 네트워크가 끊겨도 잠시 후 이어집니다.
- 그만 들을 땐 화면의 **[재생 중지]** 를 누르세요. 그 전엔 스스로 멈추지 않습니다.
- 위쪽 **[소개]** 로 네다바웨이 소개를 볼 수 있고, **[라디오로 돌아가기]** 로 바로 돌아옵니다.

## 3) 잘 안 될 때

| 증상 | 해결 |
|---|---|
| "앱 설치" 메뉴가 안 보임 | 크롬을 최신으로 업데이트 후 페이지를 새로고침. 그래도 없으면 "홈 화면에 추가"를 사용(같은 결과) |
| 옛 화면이 보임 | 앱을 완전히 종료(최근 앱에서 밀어서 닫기) 후 다시 실행 |
| 소리가 안 남 | 화면을 한 번 터치해 재생 버튼을 누름. 무음 모드·볼륨 확인 |
| 삭제하고 싶음 | 홈 화면 아이콘을 길게 누름 → **제거(설치 삭제)** |

---

**iPhone 이신 분께**: 사파리에서 같은 주소를 열고 **공유 → 홈 화면에 추가** 하면 됩니다. 단 iPhone은 화면을 오래 잠근 뒤엔 앱을 다시 열어야 소리가 이어지는 제약이 있습니다.
