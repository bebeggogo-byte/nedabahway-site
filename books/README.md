## 집필 에이전트 팀

지휘자(conductor)가 팀을 조율합니다. 정의 파일은 `.claude/agents/book/`.

| 에이전트 | 역할 |
|----------|------|
| `book-conductor` | 지휘자 — 팀 조율, 품질 게이트 검증 |
| `book-researcher` | 근거·인용·통계 수집 및 출처 검증 |
| `book-architect` | 명제·부·장 구조·서사 아크 설계 |
| `book-editor` | 김창환 문체로 본문 초안 집필·교정 |

## 워크플로

1. CLARIFY — 책별 범위·독자·분량 확정
2. RESEARCH — `research-notes.md` 작성 (근거·출처)
3. ARCHITECT — `plan.md` 작성 (명제·구조·장별 브리프)
4. DRAFT — 장별 본문 초안 집필
5. VERIFY — 문체·명제 정합성·출처 검증

## 품질 게이트

- 문체: 김창환의 차분한 2인칭, 근거 기반 문장
- 명제: 모든 장이 책의 한 줄 명제로 회귀
- 근거: 모든 통계·인용에 검증된 출처 존재
- 정합성: 장 순서가 하나의 연속된 논증을 구성
- 범위: 어떤 장도 책의 경계를 벗어나지 않음
