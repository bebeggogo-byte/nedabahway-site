LECTURE · 조직 자동화

조직 업무 자동화 실무 9선

기획 3 · HR 3 · 마케팅 3. 누구나 30분에 만들 수 있도록 설계했고, 코드·시트 템플릿·트러블슈팅까지 모두 공개합니다.

한눈에

대상기획·전략·HR·마케팅·운영 실무자, 팀장, SMB 대표
시간120분(쇼케이스) / 4시간(워크숍) / 6시간(직접 구축)
형식강의 + 라이브 시연 + 핸즈온. 노트북 1대만 있으면 됨
스택Google Apps Script · Sheets/Docs/Forms · Gemini 무료 티어 · Slack
월 운영비0원 ~ 매우 적음 (소규모 팀 기준)

왜 이 강의인가

대다수 자동화 강의는 SaaS 시연으로 끝나거나, 코드가 있어도 발표용 슬라이드에 갇혀 있습니다. 이 강의는 "강의가 끝나는 순간 9가지 자동화의 코드와 시트가 학습자 손에 그대로 남는 것"을 목표로 설계했습니다. 모든 코드는 복붙 즉시 실행되며, 시트 템플릿과 트러블슈팅 표가 함께 제공됩니다.

다루는 9가지

기획 자동화

  1. 회의록 → 액션아이템 자동 정리 — Doc 한 장이 시트·Slack으로 분해된다
  2. 경쟁사·뉴스 일일 다이제스트 — 출근 전 한 장의 메일
  3. 주간 KPI 자동 리포트 — AI가 변동·이상·권고를 함께 작성

HR 자동화

  1. 신규 입사자 온보딩 키트 — 입사자 한 줄 입력 → 메일·캘린더·Slack·체크리스트 동시 생성
  2. 휴가 신청 슬랙 승인 워크플로우 — 폼 → 팀장 슬랙 카드 → 캘린더·잔여 자동 갱신
  3. 분기 펄스서베이 + AI 감성 분석 — 응답 1,000건도 30분 안에

마케팅 자동화

  1. 30일 콘텐츠 캘린더 자동 생성 — 테마 한 줄 → 30일 헤드라인·후크·CTA
  2. 인입 리드 자동 스코어링·배정 — Hot/Warm/Cold 분류 + 담당자 즉시 알림
  3. 리뷰·멘션 주간 다이제스트 — 부정 멘션 24시간 안에 인지

전체 자료 허브로 이동 →

강의 후 가져가는 것

  1. 9가지 자동화의 완성 코드와 시트 템플릿 (즉시 실행)
  2. 자기 조직에 적용할 수 있는 첫 1가지 선택과 30분 셋업 경험
  3. "AI는 보조, 사람은 검토" 원칙이 담긴 워크플로 설계 감각
  4. 각 자동화의 트러블슈팅 표와 응용 아이디어 4가지씩

진행 방식

이 강의는 핸즈온 중심으로 진행됩니다. 강사가 1개를 라이브로 끝까지 만든 뒤, 학습자가 자기 비즈니스 데이터로 1개를 직접 구축합니다. 강의가 끝났을 때 학습자의 노트북에는 실제로 동작하는 자동화 1~3개가 남아 있어야 합니다.

인원은 10~50명이 가장 효과적이며, 100명 이상 청중일 경우 시연 중심으로 형식을 조정합니다. 온·오프라인 모두 가능하지만 핸즈온 효과가 뚜렷한 오프라인을 권장합니다.

사전 준비

  • 구글 계정 (Workspace 또는 일반 계정)
  • Gemini API 키 — 강의 시작 시 함께 발급
  • (선택) Slack Workspace · 네이버 개발자 키
  • 코딩 경험 불필요. 복사·붙여넣기만 가능하면 됨

강의료 안내

강의료는 (1) 강의 형식·시간, (2) 인원, (3) 이동 거리, (4) 기관 성격(영리/비영리/교육)을 종합해 1대1로 안내합니다. 비영리·교육기관 협의 가능합니다. 정확한 견적은 의뢰 시 회신해 드립니다.
