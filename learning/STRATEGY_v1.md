> "**고전, 인문학, 과학 등 30여 분야를 섭렵하기 위한 공부이다.**"

학습페이지의 본질은 *글을 게시하기 위한 페이지*가 아니라
**김창환 직업본질연구원가 30여 분야를 섭렵하는 학습 그 자체**다.
보고서·글은 섭렵의 **흔적·증거·재해석**이지, 목적이 아니다.

이 1줄이 모든 설계의 위에 있다. 30카테고리·30단계·KPI·UI 모두 이 문장에 종속.

## 1. 섭렵 6대 영역 — 30카테고리 재분류 (D7 + D11 + 본질 통합)

기존 4그룹(자기이해 4 / 실무 18 / 동양 5 / 서양 3)은 실무 60% 편중으로 "섭렵"이라는 본질에 어긋난다 (D7 지적). **6대 영역으로 재정렬**:

| 영역 | 카테고리(개수) | 본질 |
|---|---|---|
| **A. 고전** (5) | 동양고전·서양고전·성경신학·역사인물·문학서사 | 시간을 통과한 사고 |
| **B. 인문학** (5) | 철학윤리·심리학·사회학·문화·발달심리 | 인간을 묻는 학문 |
| **C. 과학** (5) | 데이터통계·자연생태·경제학노동·정책교육행정·**물리·생명과학(신설)** | 세계를 측정하는 학문 |
| **D. 실무** (8) | 코칭·리더십·퍼실리테이션·교육공학·HRD·기업가정신·미디어콘텐츠·코딩자동화 | 현장에 닿는 기술 |
| **E. 자기이해** (4) | 직업철학이타성·진로자기이해·관계소통·웰니스회복 | 자기 좌표 갱신 |
| **F. 예술·자연** (3) | 예술음악·시각화디자인·글쓰기편집 | 감각·표현의 자리 |

**변경점**:
- *문학서사* 22번 → 고전 영역 (동양/서양 무관)
- *부모-자녀 교육* 11번 → 실무·자기이해 양쪽 태그(중복 허용, D7 지적 흡수)
- *AI 리터러시* 6번 → 실무 + 과학(횡단)
- **신설 1건**: *물리·생명과학* (현재 빠진 자연과학 1차 출처 자리)
- 합계 30 유지 (1 신설·1 삭제 또는 통합 — 사용자 결정 사항 ①)

**사용자 결정 사항 ①**: 자연과학(물리·생명) 신설 시 어느 카테고리를 합칠 것인가? 후보:
- (a) AI 리터러시를 코딩자동화에 흡수 → 자연과학 1슬롯 확보
- (b) 시각화디자인을 글쓰기편집에 흡수 → 자연과학 1슬롯 확보
- (c) 30 유지 + 자연과학 보류 (섭렵 본질에 흠 인정)

## 2. 30단계의 의미 — "섭렵 6단계 × 5회전" (D7 B안 + 섭렵 본질 통합)

D7 권고 B안(누적 30회)은 섭렵의 깊이를 표시 못 함. 사용자 본질("섭렵")에 맞춰 **6단계 × 5회전 = 30 좌표** 모델 채택:

| 단계 | 이름 | 1회전 산출물 |
|---|---|---|
| 1 | **입문** Encounter | 첫 1차 출처 만남, 핵심 용어 10개 정리 |
| 2 | **정독** Read | 원전·논문 1편 정독 + 200자 요약 |
| 3 | **비교** Compare | 같은 주제 다른 1차 출처 1건 추가 정독 + 차이 정리 |
| 4 | **재구성** Reframe | 본인 관점으로 600~1,200자 에세이 1편 |
| 5 | **적용** Apply | 강의·코칭·일터에 1회 적용 + 일지 |
| 6 | **교수** Teach | 활동지·진단지·강의 자료로 변환 (자료실 D25 8형식 산출) |

**5회전 = 같은 카테고리를 5번 더 깊게 도는 것.** 1회전 끝나면 같은 카테고리에서 다른 주제로 1→6 다시. 30카테고리 × 30좌표 = 900좌표 = 평생 학습 매트릭스.

**가중치** (D10 산식 흡수): 입문~정독 1점 / 비교~재구성 2점 / 적용~교수 3점. 카테고리 만점 60점, 전체 1,800점.

**KPI 진척률**: `채워진 좌표 수 / 900` — 단, 900 모두 채울 필요 없다. 섭렵은 "닿음"이지 "정복"이 아니다 (사용자 IDEN 1차 좌표 수호).

**사용자 결정 사항 ②**: 6단계 정의 위 6개 이름·정의로 확정?

## 3. 데이터 SSoT + 파이프라인 (D25 + Execution Squad 통합)

### SSoT 단일 진실 원천
```
learning/_data/
├── categories.json       # 30카테고리 메타 (이미 생성됨, 6영역 재분류 필요)
├── stages.json           # 6단계 × 5회전 정의
├── notes.json            # 모든 학습 entry 단일 파일 (SSoT)
├── sources_pool.jsonl    # D11이 큐잉한 외부 1차 출처 후보
├── kpi.json              # D10 KPI 누적
└── seeds_queue.jsonl     # 다음 학습 좌표 후보

learning/_build/
├── render_all.py         # 1회 호출 = 인덱스·카테고리·단계·sitemap 자동 재생성
├── validate.py           # schema 검증 + 16원칙 source/qa/review 게이트
└── chart_gen.py          # SVG 차트 (이미 refinery_squad에 있음, 재사용)
```

**룰** (D25 IA v1 동일 원칙): 인덱스·카테고리·단계 페이지 수동 편집 영구 금지. notes.json만 수정 → render_all.py.

### 글 형식 — 학습 전용 6형식 (D25 제안)
자료실 8형식과 별도 네임스페이스:
- `paper` 논문/보고서 정독 노트
- `book` 도서 정독 노트
- `field` 현장 적용 일지
- `essay` 짧은 관점 글 (600~1,200자, 8단계 흐름)
- `diary` 학습 일기 (1줄)
- `synth` 통합 노트 (여러 자료 교차)

자료실 8형식과 학습 6형식 둘 다 같은 16원칙·source_gate·qa_gate·review_gate 통과.

### 파이프라인 (수집 → 학습 → 집필 → QA → 게시)
```
[D11 harvester] 카테고리당 5건/일 외부 1차 출처
   ↓ sources_pool.jsonl
[사용자 정독 또는 daily_research_engine writer] 학습 entry 생성
   ↓ Vault 30_RESOURCES/learning/{slug}/
[E5 Quality Gate] 16원칙 자동 검사
   ↓
[E2 Post-Delivery] notes.json append + Vault 이관 + CEO_LOG
   ↓
[E10 Pipeline] render_all.py
   ↓
[E12 HAG] visibility 결정 (public/internal/draft)
   ↓
[site_publisher] git commit + push
```

### 신규 Hook Bus 이벤트 5종 (Execution Squad)
- `learning.note_drafted`
- `learning.note_qa_passed`
- `learning.published`
- `learning.stage_advanced`
- `learning.balance_alert` (카테고리 편중 감지)

## 4. KPI 5종 + 4원칙 연결 (D10)

| KPI | 산식 | 목표 |
|---|---|---|
| **DLA** Daily Learning Add | 일일 신규 entry 수 | 일 4건 / 주 28건 |
| **CBI** Category Balance Index | 표준편차/평균 | ≤ 0.6 |
| **SAR** Stage Advance Rate | 채움 좌표 / 900 | 월 +6%p |
| **ECR** External Citation Ratio | 1차 출처 박힌 비율 | ≥ 70% |
| **L2L** Learning-to-Lecture | 학습 → 강의/제안서 인용 흐름 | 월 2건 |

**4원칙 박음**:
- 멈추지 마라 → DLA 미달 시 continuous_engine pivot
- 항상 발전 → SAR 일 +0.2%p 의무
- 항상 개발 → 도구 1개/일 = 28단계 통합 entry
- 항상 계발 → 모든 entry = lessons.jsonl record
- 목표 상향 → 주 DLA +10% 자동 escalate (28→31→34)

**카테고리 균형 강제** (D10): 평균 1.5배 초과 카테고리 24h cooldown / Underfed Top 3에 신규 40% 강제.

**1차 좌표 수호** (D25): 직업철학이타성·진로자기이해·관계소통·웰니스회복 = E영역 4카테고리 = 일일 학습 25% 미만 시 publish RuntimeError.

## 5. UI/UX (D24)

### 6영역 sticky 탭 (재분류 흡수)
- 상단: 전체 / 고전 / 인문학 / 과학 / 실무 / 자기이해 / 예술·자연
- 모바일 1열 + 영역 탭 → 스크롤 부담 1/3 감소

### 점진 공개 (0/30 비어 보이지 않게)
- 회색 도트 30개 항상 표시 → 채워질 때 청록 점등
- "다음 학습 예고" 미니 라인 + "후보 자료 N건 대기" 칩
- "작성 중" pulse 애니메이션

### 글 6형식 시각 차이
- 좌측 4px 컬러바 + 모노 아이콘 + 라벨 칩 (paper 짙은남 / book 갈색 / field 청록 / essay 보라회 / diary 옅은회 / synth 회)

### 외부/내부 분리 (D17)
- 학습페이지 외부 = public만 카드 노출 (0/30도 회색 처리, "준비 중" 라벨 — 약점 비노출)
- CEO 콘솔 = 빈 카테고리 적색·진척 분포·30단계 정의 미완 표시

## 6. 자료실 D25 vs 학습노트 — 경계 1줄 (D25)

> **자료실은 "쓸 수 있는 것"을, 학습노트는 "갱신된 것"을 보여준다.**

- 자료실 = 완성 산출물 (외부 즉시 사용)
- 학습노트 = 사고 누적 과정 (섭렵의 흔적)
- 같은 주제도 양쪽 동시 존재 가능 (의도된 중복)
- **6단계 마지막 "교수" 단계 산출물이 자료실로 승격됨** — 두 시스템 자연 연결

## 9. 위험·반대의견 (D7)

1. **자료실의 그림자 시스템 위험** — 학습노트 SSoT가 자료실과 중복·충돌 가능성. 해결: 동일 schema 적용 + 6형식 네임스페이스 분리 + classifier 자동 라우팅.
2. **빈칸 채우기 강박** — 30×30=900 슬롯이 가짜 학습 entry 양산할 위험. 해결: 회전 30 강박 해제. "닿음 가능성"만 표시. SAR 가중치(입문 1점·교수 3점)로 깊이 우선.
3. **16원칙 무력화 위험** — 자동 누적 시스템에서 가상 인물·결말 클리셰 검사 우회 가능. 해결: source_gate·qa_gate·review_gate 학습노트에도 동일 강제, E5 Quality Gatekeeper 의무 통과.
