## 1. 자료 발견처 — 4계층 신뢰 사다리

학습 자료는 신뢰도 위계로 4계층. 항상 **위에서부터** 찾고, 아래는 보조로만.

### S급 — 1차 출처 원전 (PEER 또는 ORIGINAL)
| 영역 | 발견처 |
|---|---|
| 성경·신학 | BHS(히브리)·Nestle-Aland 28(헬라)·STEPBible·Bible Hub·Logos Open Texts |
| 헬라·라틴 고전 | Perseus Digital Library(Tufts)·Loeb Classical Library·Project Gutenberg |
| 동양 고전 | 한국고전종합DB(db.itkc.or.kr)·中國哲學書電子化計劃(ctext.org)·국립중앙도서관 |
| 중세 문학 | Oxford Medieval Texts·MGH Digital |
| 철학 | Stanford Encyclopedia of Philosophy(plato.stanford.edu)·Internet Encyclopedia of Philosophy |
| 과학·수학 | arXiv·Crossref·Semantic Scholar·DOI·Royal Society Archives |
| 한국사 | 조선왕조실록·승정원일기·삼국사기·국사편찬위원회 한국사데이터베이스 |
| 이스라엘사 | Sefaria·Jewish Virtual Library(1차문헌 한정)·Israel State Archives |
| 다 빈치 | Codex Atlanticus(Biblioteca Ambrosiana 디지털)·Royal Collection Trust |
| 5거인 본인 저작 | Project Gutenberg·Internet Archive·해당 거인 비평본 |

### A급 — 학술 2차 자료 (PEER REVIEWED)
- 동료심사 논문 (DOI 박힌 것만)·대학 출판부 단행본·전문 백과사전
- 검색: Google Scholar·JSTOR·Crossref·arXiv·KCI(한국 등재지)

### B급 — 정책·통계 1차 출처 (POLICY / STAT)
- 교육부·KEDI·통계청·OECD.Stat·KOSIS·세계은행·UN·UNESCO
- 정부 1차 발표 자료 (보도자료가 아닌 원전 보고서·법령·통계 표)

### C급 — 사례용 보조 (PRESS / INFORMAL)
- 신뢰 가능한 언론(NYT·Hani·BBC) — **사례용 1건만**
- 해당 분야 전문가 블로그·뉴스레터 — 보조 신호용
- 위키피디아 — **출처 추적 도구**로만 사용 (위키 자체는 인용 금지, 위키가 가리키는 1차 출처를 직접 확인)

### 학습 가동 룰
- **1편 글당 S~A급 1차 출처 3건 이상 의무** (16원칙 13번)
- **C급 단독 인용 영구 금지** — 반드시 같은 사실을 S~B급에서 교차 확인
- 자료 발견 시 **30초 안에 신뢰 라벨 결정** (PEER/POLICY/STAT/PRESS/INFORMAL)

## 2. 자료 식별·구분 — 5단계 검표

자료 1건을 손에 들었을 때 통과해야 하는 5단계 체크. **하나라도 미통과 = 자료 폐기**.

### 검표 1. 출처 신뢰성 (Provenance)
- 저자 실명·소속·발행기관 명확한가
- DOI·ISSN·ISBN·발행일 확인 가능한가
- 1차 출처를 인용하고 있는가 (재인용 사슬 추적)

### 검표 2. 시간성 (Recency vs Timelessness)
- **고전·신학**: 시간 무관, 비평본 권위 우선 (Loeb·Nestle-Aland)
- **과학·정책·통계**: 5년 이내 우선, 10년 이상은 역사적 맥락용
- **인문학·철학**: 2차 자료는 20년 이내, 1차는 영구

### 검표 3. 1차성 (Primary vs Secondary)
- **원전 vs 해설서** 구분. 항상 원전 직독을 1순위.
- 해설서 인용 금지가 아니라, 해설서가 가리키는 원전 페이지를 같이 확인.
- 라이프니츠를 알려면 라이프니츠를 읽지 라이프니츠 입문서만 읽지 않는다.

### 검표 4. 편향 (Bias)
- 정치·종교적 편향 자료는 **반대편 자료 동시 검토** 의무
- 단일 학파만 보면 학파 안에 갇힘 (예: 보수 신학만, 진보 신학만)
- 5거인 모두가 자기 시대 양극단을 동시에 읽었음

### 검표 5. 검증 가능성 (Reproducibility)
- 통계는 표본·기간·정의 1줄 명시 가능한가
- 데이터셋 출처를 다시 찾을 수 있는가
- 인용을 추적해 원전까지 도달 가능한가

→ **5단계 모두 통과 자료만** `learning/_data/sources_pool.jsonl`에 등재.

## 3. 퀄리티 검증 — 4관문 게이트

학습 entry가 발행되기까지 통과해야 하는 4관문. 자동(코드) + 수동(사용자 본인) 결합.

### 관문 1. SourceGate (자동)
- `_build/validate.py`가 schema 검증
- `source` 필드 필수 (16원칙 9번 — 자료 없으면 글 X)
- `cites` 배열에 1차 출처 3건 이상 (16원칙 13번)
- 모든 인용에 신뢰 라벨([PEER]/[POLICY]/[STAT]/[PRESS]/[INFORMAL]) 부착
- 외부 직접 인용 30단어 이내·1건 한도 (16원칙 16-c)
- 통계 인용 시 표본·기간·정의 1줄 동반 (16원칙 16-d)

### 관문 2. QAGate (자동) — 글 자체 검사
- 가상 인물 패턴 0건 (16원칙 8번)
- 결말 클리셰 0건 (16원칙 10번 — BANNED_ENDINGS)
- 금지 어휘 0건 ("박는다·박혀·박혔다·박힘·박을까·박음" 등 사용자 지시 2026-04-30)
- PHRASE_QUOTA 통과 (16원칙 12번 — "한 줄"·"그분" 빈도 한도)
- 자기 모방 검사 (직전 4편과 5-gram 중복률 15% 미만)
- 글자 수 600~1,200자 (essay) / 형식별 다른 한도

### 관문 3. ReviewGate (수동) — 사용자 자가 검토
- 4편 발행 후 1편씩 다시 읽기 의무 (16원칙 11번)
- 자기 의심 작업 중단 명분 금지 — 끝낸 다음 평가 (7원칙 4번)
- review_done=True 명시 후 다음 4편 작성 가능

### 관문 4. PublishGate (자동) — visibility·라우팅
- public/internal/draft 결정
- 1차 좌표 카테고리(직업이타성·진로·관계·웰니스) 25% 미만 시 RuntimeError (1차 좌표 수호)
- 균형 위반 (특정 카테고리 평균 1.5배 초과) 시 24h cooldown
- git commit + push (외부영향 7종 중 "공개게시" → 자동 승인 룰 적용)

## 4. 글 쓰는 방식 — 형식별 6프로토콜

학습노트 6형식마다 **다른 작법**. 같은 매뉴얼 X.

### Protocol P (paper) — 논문/보고서 정독 노트
- 800~1,500자
- 구조: ① 논문 식별(저자·연도·DOI) → ② 연구 질문 1줄 → ③ 방법론 요약 → ④ 핵심 결과 3개 → ⑤ 본인 갱신 1줄(이 논문이 내 좌표를 어떻게 옮겼나) → ⑥ 다음 추적 자료 1건
- 의식흐름 9~13단계 작동 (논리 우선)

### Protocol B (book) — 도서 정독 노트
- 1,200~2,000자
- 구조: ① 책 식별 → ② 저자 좌표(저자가 이 책에서 무엇과 싸웠나) → ③ 핵심 명제 1줄 → ④ 장별 인용 3개(30단어 이내) → ⑤ 본인 반론·동의 → ⑥ 5거인 중 누구의 자리와 닿는가 → ⑦ 다음 1권
- 의식흐름 1~15단계 전부 작동

### Protocol F (field) — 현장 적용 일지
- 600~1,000자
- 구조: ① 적용 맥락(어느 강의·코칭) → ② 어느 학습 자료 적용했나 → ③ 일어난 일(사실만) → ④ 본인 갱신 → ⑤ 다음 적용 가설
- 감정흐름 9단계 우선

### Protocol E (essay) — 짧은 관점 글
- 600~1,200자
- 구조: 이 문서 §5 의식 15단계 + §6 감정 9단계 흐름 그대로
- WFO 문체 12특성 3개 이상 작동
- 1만 편 매뉴얼 8단계 흐름 통과

### Protocol D (diary) — 학습 일기
- 100~300자
- 구조: 그날 닿은 자리 1줄 + 의문 1개 + 다음 1단위
- 감정흐름 1~3단계만 (호기심·안도·공감 자리)

### Protocol S (synth) — 통합 노트
- 1,500~3,000자
- 구조: ① 통합할 자료 3건 이상 식별 → ② 공통 명제 → ③ 차이 → ④ 본인 종합 → ⑤ 어느 카테고리·기둥 5개 이상 횡단했나
- 의식흐름 + 감정흐름 동시 풀가동
- 6단계 마지막 "교수" 산출물의 원형

## 5. 의식흐름 15단계 (사용자 직접 지시, 2026-04-30)

기존 8단계(주의→공감→문제→질문→답→사례→적용→여운) 확장. 15단계로 더 두껍게.

| 단계 | 이름 | 독자에게 일어나는 일 |
|---|---|---|
| 1 | 주의 끌기 | 첫 한 줄에 시선 멈춤 |
| 2 | 공감대 | "내 자리도 그렇다" |
| 3 | 문제 명확화 | 막연한 답답함이 형체를 갖춤 |
| 4 | 질문 던짐 | "왜 이런가" 의식 위로 |
| 5 | 가설 제시 | 답의 방향 1줄 |
| 6 | 1차 근거 | 1차 출처 인용 (PEER/POLICY) |
| 7 | 반례 검토 | 반대 자료 1건 인정 |
| 8 | 깊이 풀이 | 표면 너머 구조 (다 빈치 해부 자리) |
| 9 | 비교 자리 | 다른 시대·문화·학파와 비교 |
| 10 | 사례 배치 | 운영자 본인 일화 1건 (가상 인물 X) |
| 11 | 초보자 다리 | 어려운 개념을 일상 비유로 |
| 12 | 종합 명제 | 한 문장 결론 |
| 13 | 적용 안내 | 독자가 오늘 할 1동작 |
| 14 | 한계 표시 | 이 글이 답 못 한 자리 1줄 |
| 15 | 다음 자리 | 후속 학습·다음 글로의 손짓 |

→ 15단계 전부 1편에 들어갈 필요는 없다. **형식별 필수 단계 매핑**:
- essay: 1·2·3·4·6·7·11·12·13·15 (10개)
- paper: 1·5·6·7·8·9·12·14·15 (9개)
- book: 1·2·6·7·8·9·10·11·12·15 (10개)
- synth: 1·6·7·8·9·11·12·13·14·15 (10개)
- field: 1·2·3·10·12·13·15 (7개)
- diary: 1·4·15 (3개)

QAGate가 형식별 필수 단계 출현 여부 자동 검사.

## 6. 감정흐름 9단계 (사용자 직접 지시, 강화)

기존 9단계(호기심→안도→공감→흥미→인지→감동→자기적용욕구→결심→여운) 유지하되, 단계별 **유발 트리거 어휘** 신설.

| 단계 | 감정 | 유발 자리 (글에서 어디에서 일어나는가) |
|---|---|---|
| 1 | 호기심 | 의식 1·4단계 (주의·질문) |
| 2 | 안도 | 의식 2단계 (공감대 — "혼자가 아니구나") |
| 3 | 공감 | 의식 2·10단계 (사례 닿음) |
| 4 | 흥미 | 의식 4·5·8단계 (질문·가설·깊이) |
| 5 | 인지 | 의식 6·7·9·12단계 (근거·반례·비교·결론) |
| 6 | 감동 | 의식 8·10·14단계 (구조 풀림·진솔한 사례·한계 인정) |
| 7 | 자기 적용 욕구 | 의식 11·13단계 (초보자 다리·1동작) |
| 8 | 결심 | 의식 13·15단계 (오늘 할 일·다음 자리) |
| 9 | 여운 | 의식 15단계 (다음으로의 손짓) |

→ 감정흐름은 의식흐름과 **나란히 흐름**. QAGate는 의식 단계 통과 시 감정 단계 자동 매핑 점검.

## 7. 논리·근거 + 초보자 이해 — 4중 다리

어려운 자료를 초보자가 이해하면서 동시에 학자가 인정할 깊이를 갖추는 4가지 다리.

### 다리 1. 1차 출처 + 초보자 비유 동시 노출
- 라이프니츠 모나드론 인용(PEER) 직후 → "이건 마치 한 사람의 영혼이 거울처럼 우주 전체를 비추는 자리" 식의 일상 비유
- 인용 30단어 + 비유 30~50단어 = 한 단락에 학자·초보자 동시 닿음

### 다리 2. 정의 다시 쓰기 (사전 정의 → 본인 정의)
- "수사학(rhetoric)이란 흔히 X로 정의된다. 그러나 본 글에서는 Y로 다시 정의한다."
- WFO 문체 12특성 중 "사전 정의 다시 쓰기" 자리

### 다리 3. 비유·도식·차트 1개 의무
- essay·book·synth는 본문에 **시각 자료 1개 이상** (assets 필드)
- 자체 SVG 차트 (chart_gen.py) 또는 1차 출처 라이선스 OK 이미지
- 차트는 "이걸 안 보면 못 따라옴" 자리에만, 장식용 X

### 다리 4. 두 언어 분류 (전문어 + 일상어)
- 전문어가 처음 등장하면 괄호로 일상어 동시 (WFO 12특성 중 하나)
- 예: "독사(δόξα, 의견) — 흔히 갖는 생각의 자리"

## 8. 진짜 학습시키는 전략 — 5단 학습 엔진

자료를 넣으면 글이 나오는 단순 파이프라인 X. **사용자 본인의 사고가 갱신되는** 학습 엔진.

### 단계 1. 사전 학습 큐 (Pre-Learning Queue)
- D11 정보부가 매일 02:00에 카테고리당 5건 1차 출처 자동 수집
- 5단계 검표(§2) 통과 자료만 `sources_pool.jsonl`로 진입
- 사용자가 다음 학습 자료 결정 부담 0 (자료가 미리 와 있음)

### 단계 2. 정독·갱신 (Read & Reframe)
- 사용자 본인이 직접 자료 1건 정독 (또는 daily_research_engine writer가 1차 초안)
- 정독 후 200자 본인 갱신(reframe) 1줄 의무 — "이 자료가 내 좌표를 어떻게 옮겼나"
- 갱신 0이면 발행 차단 (자료만 옮긴 것은 학습 X)

### 단계 3. 비교·연결 (Compare & Connect)
- 같은 주제 다른 1차 출처 1건 추가 (스테이지 3 = Compare)
- 두 자료의 공통점·차이점 1줄
- 5거인 중 누구의 자리와 닿는지 1줄 (5거인 매트릭스 자동 매핑)

### 단계 4. 적용·교수 (Apply & Teach)
- 강의·코칭·일터에 1회 적용 (스테이지 5)
- 활동지·진단지·강의 자료로 변환 (스테이지 6)
- 6단계 산출물은 자료실 D25로 자동 승격

### 단계 5. 회전·심화 (Rotate & Deepen)
- 1회전 완료 후 같은 카테고리 다른 주제로 1→6 다시
- 5회전 = 30좌표 = 한 카테고리 평생 학습 닫음
- 회전 사이마다 본인 좌표 갱신 1줄 의무 (회전 N에서 N+1로 무엇이 바뀌었나)

### 학습 엔진의 가드레일
- **공부 부재 작업 금지**: 자료 0건 = 글 0건 (16원칙 9번)
- **회전 강박 해제**: 5회전 다 채울 필요 없음. 30좌표 중 5좌표만 채워도 한 카테고리 닿음 인정
- **균형 강제**: 7기둥 중 5기둥 이상 매일 닿기 (CBI ≤ 0.6)
- **1차 좌표 수호**: 직업이타성·진로·관계·웰니스 4카테고리 일일 학습 25% 의무
- **자국 0 룰**: 직전 4편과 5-gram 중복 15% 초과 시 폐기·재집필
