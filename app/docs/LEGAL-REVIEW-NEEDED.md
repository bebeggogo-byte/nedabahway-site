# LEGAL-REVIEW-NEEDED

## 변호사 30분 자문이 필요한 미해결 이슈 (런칭 전 1회 상담 권장)

### 1. 청약철회권 vs 환불 4구간 정합성

**현 정책** (`/refund-policy`):
- 24시간 이내: 100%
- 1회차 시작 전: 50%
- 1회차 종료 ~ 2회차 시작 전: 30%
- 그 외: 0%

**법적 쟁점**:
- 한국 소비자기본법 제17조(전자상거래법 제17조 제1항)는 **콘텐츠를 직접 제공받기 전 7일 이내 무조건 청약철회**를 보장합니다.
- 다만 "디지털 콘텐츠로서 이용 시작과 함께 그 효용이 소멸되는 경우"는 예외(전자상거래법 제17조 제2항 5호).
- 1:1 코칭은 "디지털 콘텐츠"에 해당하는지, 1회차 시작이 "이용 시작"인지 모호.

**자문 질문**:
1. 24h 100% 환불을 7일로 확장해야 하는가?
2. 1회차 시작이 "이용 개시"로 해석되는가? 그렇다면 50% 구간은 7일 무조건 환불 후 비율 차감으로 재구성해야 하는가?
3. 환불정책을 청약철회권과 충돌하지 않는 형태로 어떻게 작성해야 하는가?

**예상 결과**:
- A안: 정책 그대로 유지 가능 (변호사 견해)
- B안: 7일 무조건 환불 + 차감 구조로 재작성

### 2. 만 14세 미만 보호자 동의 방법

**현 구현**:
- 회원가입 시 보호자 이메일 입력
- 보호자 이메일로 동의 링크 발송 (1회 클릭으로 동의 성립)
- `parental_consents` 테이블에 동의 기록 (이메일·시각·IP)

**법적 쟁점**:
- PIPA 22조 + 시행령 17조는 보호자 동의 방법으로 다음을 예시:
  - 동의서 우편·팩스 송부
  - 동의서를 신용카드·핸드폰 본인인증 등으로 확인
  - 직접 통화로 확인
  - 그 밖에 이에 준하는 방법
- "이메일 1회 클릭"이 "준하는 방법"으로 인정되는지 불확실.
- 분쟁 시 보호자가 "내가 동의한 적 없다"고 주장하면 입증 책임은 회사.

**자문 질문**:
1. 이메일 링크 클릭 방식만으로 PIPA 22조 동의 요건 충족?
2. 추가로 핸드폰 본인인증(또는 신용카드 본인인증)을 결합해야 하는가?
3. 결합 시 어느 시점(회원가입 시 / 결제 시)에 받아야 효력이 가장 강한가?

**예상 결과**:
- A안: 이메일 동의로 충분 + 약관에 명시
- B안: 이메일 + 핸드폰 본인인증 2단계 (NICE 평가정보 등 본인인증 API 연동 — 별도 SPEC 필요)

### 3. 결제 시 동의 기록의 법적 효력

**현 구현**:
- `consents` 테이블에 결제 시점의 약관 버전·IP·UA 기록
- 마이그레이션 0004 참조

**법적 쟁점**:
- 약관 동의 기록의 보존 기간 (5년? 영구?)
- 약관 개정 시 기존 회원 재동의 절차 (별도 알림? 동의 거부 시 자동 탈퇴?)

**자문 질문**:
1. 약관 동의 기록 보존 기간은 어느 정도가 적절한가?
2. 약관 개정 시 재동의 받지 않으면 기존 회원은 변경된 약관에 자동 동의한 것으로 보는가?
