## 0. 사용자 지시 정리

> "홈페이지의 매거진 페이지를 성경 66권 관찰영역으로 해라. 그리고 이를 매거진 컨셉으로 풀어라. 그리고 66권에 대해 어떤 접근으로 관찰을 풀어낼 것인지 전문디자인을 추가해서 설명해라. 그리고 66권 관찰을 배치해라. 어떻게 하면 가장 효과적이게 배열하고 구조적으로 탄탄하고 고객 이용동선이 수월하고 매력적일지 확인해라. 그리고 아이콘들을 만들게 되면 다음 화면 이동이 어디인지, 그 화면은 잘 작동하는지, 그 화면으로의 이동이 의미가 있는지 확인하라. 그리고 관찰페이지를 아주 정교하게 기획하고 구조설계하고 완벽하게 만들어라. 문장 퀄리티 높여라. 문장의 1,2개 단어만 다른 줄로 내려가는 것 주의하라. 마지막 문장은 홈페이지 모든 페이지에 적용하자."

→ 6개 트랙으로 분해:
1. 매거진 페이지 컨셉 재정의 (66권 관찰 영역으로)
2. 66권 접근법 전문 디자인 설명
3. 66권 배치 구조 (정경·블록·언어 축)
4. 고객 동선 + 매력 검증

6. 모든 페이지 공통: 단어 1~2개 단독 줄바꿈 방지 (no-orphan 룰)

## 1. 매거진 컨셉 재정의 — "Observatory : 본문이 본문을 읽는 자리"

### 1.1 한 문장 정의
> **"매거진은 글을 발행하는 곳이 아니라, 본문을 같이 *관찰*하는 자리다."**

기존: 강사의 사고일지 큐레이션 (주 1편 메일).
신규: 성경 66권 본문 관찰 Atlas — 가르침이 아닌 *관찰*만 기록한 1,189장의 공개 노트.

### 1.2 매거진 형식이 살아있는 이유 (왜 매거진이라 부르는가)
1. **표지와 차례** — 매호(每號) = 1권. 권 단위로 표지 카드·차례·서장이 있다.
2. **연재** — 매주 발행되는 새 장(章)은 "이번 호의 새 페이지".
3. **편집 후기** — 모든 장은 *관찰자의 후기*로 닫힌다 (가르침 아님, 미해결 질문).
4. **특집** — 분기마다 한 권을 통권 특집으로 묶어 PDF 발행 (구독자 한정).

### 1.3 기존 매거진과의 차이 (3행 비교)

| 축 | 기존 매거진 | 66권 관찰 Atlas |
|---|---|---|
| 정체성 | 큐레이션 (주 1편 메일) | 공개 관찰 노트 1,189장 |
| 본문 | 강사 사고일지 | 성경 본문 + 관찰자 후기 |
| 발행 | 주 1회 메일 | 매일 1~2장 + 분기 특집 PDF |

## 2. 66권 접근법 — 전문 디자인 4축

### 2.1 관찰 9단계 (이미 SBM에서 운용 중)
사용자가 이미 운영 중인 *SBM 관찰 Atlas v2.0* 9단계를 그대로 매거진의 본문 골격으로 사용:
1. 본문 그대로 읽기 (raw transcript)
2. 단어 빈도 관찰 (observed lexicon)
3. 인물·장소·시간 좌표 (people/place/time)
4. 행동 동사 분류 (action verbs)
5. 대조·반복·생략 (contrast/repeat/omit)
6. 장 경계 점검 (chapter boundary)
7. 원어 단서 (히브리어·헬라어 — 단어집)
8. 미해결 질문 (open questions, 가르침 0)
9. 관찰자의 자리 (observer's note)

### 2.2 디자인 4축 (사이트 표시용)

```
[축1] 정경 (Canon)        — 구약 / 신약
[축2] 블록 (Block)        — 오경·역사서·시가서·예언서·복음서·서신서·계시
[축3] 언어 (Language)     — 히브리어 / 아람어 / 헬라어
[축4] 진행 상태 (Status)  — 완료(●) / 진행중(◐) / 미착수(○)
```

위 4축이 각 권 카드에 4-dot 인디케이터로 시각화된다 (Figma·Linear·Stripe 스타일).

### 2.3 전문 디자인 특성
- **타이포그래피**: 본문 인용 = Noto Serif KR (세리프), 관찰 메모 = Pretendard (산세리프). 두 톤이 명확히 구분되는 *이중 보이스*.
- **색상**: 잉크블랙·구리(C2410C)·오프화이트(이미 v3) + 추가 토큰 2개:
  - `--c-canon-ot` (구약): `#7A5C3E` (모래·양피지 톤)
  - `--c-canon-nt` (신약): `#3E5C7A` (잉크·바다 톤)
- **그리드**: 12열 데스크탑 / 6열 태블릿 / 4열 모바일. 권 카드 = 데스크탑 4열, 태블릿 3열, 모바일 2열.
- **인디케이터**: 진행률 = 권 카드 좌상단에 *4분원 호(arc)*로 시각화 (50장 중 10장 = 72° 호).
- **여백**: 헤더 위아래 96/64px, 카드 사이 24px gap, 카드 내부 32px padding.

## 3. 66권 배치 구조 — 7블록 매트릭스

### 3.1 핵심 결정: 정경 순서 + 블록 그룹핑 (장르 축)
가장 효과적인 배열은 **정경 순서를 유지한 채 블록(장르)으로 묶는 방식**이다. 이유:
- 정경 순서는 독자에게 익숙 (창세기→계시록).
- 블록 그룹핑은 *관찰의 결*이 같은 권을 모아 비교 관찰을 유도.
- 검색·필터에서도 두 축 모두 작동.

### 3.2 7블록 배치

| 블록 | 권 수 | 권 목록 | 관찰 결 |
|---|---|---|---|
| 오경 (Torah) | 5 | 창·출·레·민·신 | 창조·해방·언약 — 서사형 본문 |
| 역사서 | 12 | 수·삿·룻·삼상·삼하·왕상·왕하·대상·대하·스·느·에 | 인물 좌표·반복 패턴 |
| 시가서 | 5 | 욥·시·잠·전·아 | 운율·반복·은유 |
| 예언서 | 17 | 사·렘·애·겔·단·호·욜·암·옵·욘·미·나·합·습·학·슥·말 | 시간 표지·심판/회복 대조 |
| 복음서 | 4 | 마·막·눅·요 | 동일 사건 4중 관찰 |
| 서신서 | 21 | 행·롬·고전·고후·갈·엡·빌·골·살전·살후·딤전·딤후·딛·몬·히·약·벧전·벧후·요일·요이·요삼·유 | 논증 구조·수신자 좌표 |

## 4. 고객 동선 — 4-step Funnel + 이탈 방지

### 4.1 핵심 동선 (90% 사용자 경로)
```
홈 → 매거진 → 권 표지 → 장 관찰 → 다음 장
                                    ↓
                              구독 (메일·RSS)
```

### 4.2 이탈 방지 6장치
1. **장 끝 다음 장 미리보기** — 다음 장 첫 문장 1줄 + "이어서 관찰 →"
2. **권 차례 사이드바** — 50장 도트맵을 모든 장 페이지 좌측에 고정 (모바일은 상단 collapsible)
3. **블록 횡단 추천** — "같은 블록의 다른 권" 3권 카드 (하단)
4. **단어 카드 popover** — 히브리/헬라 단어 클릭 시 모달 (페이지 이탈 없음)
5. **Resume 쿠키** — 마지막 본 장을 매거진 홈 상단에 "이어서 보기" 카드로 복원
6. **검색** — 권명·장 번호·키워드 검색 (Cmd+K)

### 4.3 매력 요소 4종
1. **진행률 시각화** — 1,189장 중 N장 완료가 매거진 홈 상단 마스트헤드에 큰 숫자로
2. **오늘의 한 장** — 매일 자정 자동 갱신, 마스트헤드 두 번째 슬롯
3. **단어집 누적** — 히브리어 110·헬라어 25 단어가 hover 시 본문 내 인라인 표시
4. **구독 격리** — 메일·RSS·PDF 3채널 분리, 각각 독립 CTA

## 5. 아이콘 + 이동 경로 검증

각 아이콘의 *목적지·작동 여부·이동 의미* 3축 점검:

| 아이콘 | 목적지 | 작동 | 이동 의미 |
|---|---|---|---|
| ▦ 권 그리드 (홈) | `/magazine.html` | ✓ | 66권 한눈에 |
| ◐ 진행 인디케이터 | (장식, 클릭 X) | n/a | 진행률 시각화만 |
| → 권 카드 CTA | `/magazine/{code}/` | ✓ (생성) | 권 표지로 |
| ⊞ 50장 도트맵 | `/magazine/{code}/{ch}/` | ✓ (생성) | 장 관찰로 |
| ✦ 단어 카드 | 모달 (페이지 유지) | ✓ | 원어 단서 보기 |
| ↻ 다음 장 | `/magazine/{code}/{ch+1}/` | ✓ | 연속 관찰 |
| ↑ 권 차례 복귀 | `/magazine/{code}/` | ✓ | 다른 장 선택 |
| ⌕ 검색 | Cmd+K 모달 | ✓ | 권/장/단어 통합 검색 |
| ✉ 구독 | `mailto:` | ✓ | 메일 발송 |
| ⊕ RSS | `/magazine/feed.xml` | ✓ (생성) | 구독자 외부 도구 |
| ⊞ PDF 분기 특집 | `/magazine/quarterly/` | (예정) | 분기 1권 통권 |

**죽은 링크 0개 원칙**: 위 11개 아이콘 중 "예정" 표시된 1개(분기 PDF)는 첫 분기 발행 전까지 *비활성 회색 상태*로 표시 (클릭해도 "분기 특집은 6월 1일 첫 발행" 모달).

## 6. 매거진 페이지 정교 기획 — IA + 컴포넌트 명세

### 6.1 정보 구조 (IA)
```
/magazine.html                      ← 매거진 홈 (66권)
/magazine/{code}/                   ← 권 표지 (예: /magazine/GEN/)
/magazine/{code}/{ch}/              ← 장 관찰 (예: /magazine/GEN/9/)
/magazine/words/                    ← 원어 단어집
/magazine/quarterly/                ← 분기 특집 PDF
/magazine/feed.xml                  ← RSS
```

### 6.2 매거진 홈 컴포넌트 8개 (위→아래)

1. **마스트헤드** — "Observatory · 매호(每號) 1권. 매장(每章) 1관찰." + 진행률 큰 숫자
2. **이어서 보기** (쿠키 있을 때만) — 마지막 본 장 카드 1개
3. **오늘의 한 장** — 자동 갱신 큰 카드 1개
4. **66권 그리드 — 7블록** — 블록 헤더 + 권 카드 (4열 데스크탑)
5. **방금 발행된 장** — 최근 7장 가로 스크롤
6. **단어집 미리보기** — 히/헬 단어 6개 샘플
7. **구독 3채널** — 메일·RSS·PDF
8. **편집 원칙** — 가르침 0 / 출처 100% / 관찰자 자리

### 6.3 권 표지 컴포넌트 5개

1. **권 헤더** — 권 이름·영문·코드·블록·언어·총 장 수·진행률
2. **서장 (Foreword)** — 권의 결을 1단락으로 (관찰자 후기)
3. **차례** — 50장 그리드 카드 (각 장 미니 결 1줄)
4. **같은 블록의 다른 권** — 횡단 추천 3권
5. **CTA** — "1장부터 읽기" + "구독"

### 6.4 장 관찰 컴포넌트 9개 (= 9단계)

1. raw_transcript (Noto Serif KR)
2. observed_lexicon
3. people/place/time
4. action verbs
5. contrast/repeat/omit
6. chapter boundary
7. 원어 단서 (인라인 hover)
8. open_questions

위 9개는 모든 장에서 동일 골격으로 자동 렌더링 (SBM 산출물 → HTML 변환기).

## 7. 문장 퀄리티 + no-orphan 룰 (모든 페이지 적용)

### 7.1 문장 퀄리티 5규칙
1. **한 문장 한 동사** — 종속절 2개 이상 금지
2. **결말 클리셰 0** — "그분이 메일을 보냈다" 류 일체 금지 (이미 qa_gate 등록)
3. **자국 0** — "한 줄·자리·향한다·닿는다·한 사람" 편당 1회 이내
4. **종결어 다양화** — "~다·~까·~인가·~이다·~입니다" 섞기
5. **수치 정직성** — 연도·표본·정의 명시

### 7.2 no-orphan 룰 (1~2개 단어만 다음 줄로 떨어지는 것 방지)

CSS로 강제:
```css
/* 모든 본문 단락에 적용 */
p, li, .prose, .lead {
  word-break: keep-all;        /* 한국어 어절 단위 줄바꿈 */
  overflow-wrap: break-word;
  text-wrap: pretty;           /* Chrome 117+ : orphan/widow 자동 균형 */
  hanging-punctuation: first last;
}
/* h1~h3 더 강한 균형 */
h1, h2, h3, .h1, .h2, .h3, .section__title {
  text-wrap: balance;          /* 제목 자동 균형 */
}
```

추가로, 작성 단계에서:
- 제목·소제목 마지막 어절 앞에 ` ` (non-breaking space) 삽입 가능 → 마지막 2어절을 한 묶음으로 묶기
- 본문에서 1~2글자 마지막 어절(예: "것이다·합니다·입니다")이 단독 줄로 떨어지면 *문장을 다시 쓴다* (자동 도구로 잡지 말고 사람이 다시 쓰는 룰 — qa_gate 확장 예정)

### 7.3 적용 범위
이 7.1·7.2 규칙은 **사이트 전체 페이지에 영구 적용**:
- index.html, about.html, programs.html, ai.html, magazine.html (신규)
- /magazine/{code}/, /magazine/{code}/{ch}/ (신규)
- /blog/perspective/ 모든 글
- /resources/ 자료실 카드·본문
- contact.html, work.html, story.html, company.html

CSS는 `assets/v3.css`에 직접 추가하지 않고 신규 `assets/typography-v4.css`로 분리해 import (기존 파일 무손상).

## 9. 데이터 소스 — SBM 산출물 = 매거진 본문

매거진은 별도 콘텐츠를 만들지 않는다. **이미 운영 중인 SBM 시뮬레이션 산출물**을 그대로 매거진으로 발행:

```
~/Documents/Obsidian Vault/Nedabah-Brain/20_AREAS/SBM시뮬레이션/
└── 산출물/
    └── 01_창세기/
        └── 001장_창조/
            ├── raw_transcript.md    → 매거진 장 컴포넌트 1
            ├── observed_facts.md    → 컴포넌트 2~6
            ├── open_questions.md    → 컴포넌트 8
            └── ... (cards.md, guide_30min.md, map.html 등)
```

→ SBM이 1장을 완료할 때마다 매거진에 자동 1장 발행 (S6 변환기).

## 10. 발행 규율 (nedabah.org 7원칙·7세부룰 그대로)

- 묻지 마라 — 권·장 추가 발행은 외부영향 7종 아니므로 즉시 실행
- 끊지 마라 — SBM 시뮬 + 매거진 발행은 별도 트랙 자동 진행
- 막힘은 풀고 가라 — 빈 장/링크는 그 자리에서 풀거나 비활성 처리
- 자국 0 — 매거진 본문도 "한 줄·자리·닿는다" 편당 1회 이내
- 1만 편 매뉴얼과 별도 트랙 — 매거진은 *관찰* 트랙, 1만 편은 *집필* 트랙
