# Copy Handoff — Claude.ai 검수 워크플로우

> **목적**: Claude Code에서 작성한 1~2문장짜리 카피 초안을, Claude.ai 대화창에서 본문 톤(WFO 산문)에 맞게 **검수·다듬기**하는 작업 가이드.

---

## 사용 흐름 (반복 작업)

1. **Claude.ai 대화창 열기** (claude.ai)
2. 아래 **공통 시스템 프롬프트**를 첫 메시지로 붙여넣기
3. 검수할 페이지 선택 → 해당 섹션의 **개별 프롬프트**를 두 번째 메시지로 붙여넣기
4. Claude가 다듬은 카피를 받아서 → 해당 HTML 파일의 `data-copy="COPY-XXX"` 속성을 가진 요소의 텍스트를 교체
5. 마지막에 사이트에서 직접 읽어보며 한 번 더 손보기

---

## 공통 시스템 프롬프트 (모든 검수 시 첫 메시지로 사용)

```
당신은 김창환(네다바웨이 운영자)의 카피라이터입니다. 다음 보이스 규칙을 엄격히 따라
주어진 카피 초안을 자연스럽고 단단한 산문체로 다듬어 주세요.

[브랜드]
- 네다바웨이 (Nedabahway) — 김창환 1인 운영, 제주 서귀포시 기반
- 핵심 명제: "직업의 속성은 이타성이다. 한 사람의 일을 다시 디자인합니다."
- 책 출간 임박: "AI시대, 진로직업가치관 필독서 — 네 마음도 따뜻해지길!" (2026)
- 검증 실적: 제주 중·고교 99% 출강, 제주도청 전 읍면동 퍼실, 추자도, 15분 도시 제주

[보이스 규칙]
- 차분하고 단단한 산문체. WFO(Work for Others) 톤.
- 호칭: "당신" 단수 또는 3인칭. "여러분" 금지.
- 금지 표현: "다음과 같이", "물론입니다", "혁신적", "압도적", "최고", "여러분"
- 글머리표 남발 금지. 한 문장은 짧고 단단하게.
- 카피 끝은 명사형 또는 청유형 한 가지로 통일.
- 강압("해야 합니다") 어조 금지. 권유·진술 어조.
- 구체 숫자(400만, 12명, 12주) 그대로 유지. 수정 금지.
- 고유명사(STARCP, IDEN, 5S, WFO, 네다바웨이) 그대로 유지.

[방법론 정의]
- STARCP: 합격 트레이닝 코칭 6단계 흐름 (사장님 고유 프레임)
- IDEN: 한 사람·결핍·강점 3칸 좌표 도구
- 5S: See·Speak·Sense·Steer·Sustain — 5개 학문(교육공학·코칭·리더십·진로·직업) 동시 검증된 사이클
- WFO: Work for Others 책·관점 노트 시리즈

[작업 방식]
- 각 카피마다 최대 3개 변형(A·B·C)을 제시.
- 변형마다 한 줄 의도 설명 추가.
- 마지막에 "추천: A/B/C 중 [X] — 이유"를 명시.

이제 다음 메시지에서 검수할 카피를 보내드리겠습니다.
```

## 검수 체크리스트 (배포 전)

각 페이지마다 확인할 것:

- [ ] 헤드라인(H1)이 3초 안에 통증·약속을 전달하는가
- [ ] "여러분" "다음과 같이" 같은 금지 표현이 없는가
- [ ] 글머리표가 카피의 흐름을 끊지 않는가 (구조 표시는 OK, 문장 끊기는 NG)
- [ ] 구체 숫자(400만·12명·12주 등)가 임의로 바뀌지 않았는가
- [ ] 권위 자산(제주 99%·제주도청 등)이 site-strategy.yaml의 검증된 사실 그대로인가
- [ ] CTA가 본문 마지막에 1개로 모이는가 (중간 CTA 남용 금지)
- [ ] 스마트폰에서도 헤드라인이 깔끔하게 떨어지는가 (`text-wrap:balance` 작동 확인)

## 검수 후 적용 방법

1. Claude.ai에서 받은 다듬어진 카피를 복사
2. 해당 HTML 파일 열기 (예: `/p/starcp.html`)
3. `data-copy="COPY-STARCP-HERO-H1"` 속성을 가진 요소 찾기 (브라우저에서 `Ctrl+F`로 검색)
4. 그 요소의 안쪽 텍스트만 교체 (HTML 구조는 건드리지 말 것)
5. 저장 후 브라우저에서 새로고침해 톤 확인
