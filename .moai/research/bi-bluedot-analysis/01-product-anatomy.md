> "구글 SEO를 잘해도 ChatGPT는 당신을 모른다. AI 검색이 답할 때 당신 브랜드가 거기 있도록, 매일 측정하고 사각지대를 콘텐츠로 메운다."

세일즈 카피로 확인된 클레임:
- **"브랜드/제품 가시성을 30% 이상 개선"**
- **"AI 검색 시대 컴머스 마케팅 전략 수립을 돕는 도구"**
- **"지금 무료 체험하세요"** (pricing 페이지 CTA)

## 1.4 핵심 지표 (KPI) 카탈로그

### Tier 1: 대시보드 최상단 (히어로 카드 3개)

| 지표 | 의미 | 산식 |
|---|---|---|
| **브랜드 가시성** (Brand Visibility) | AI 답변 안에서 우리 브랜드/제품이 등장하는 비율 | `brand_mentions / total_responses` |
| **도메인 인용률** (Domain Citation Rate) | AI 답변이 우리 사이트 URL을 출처로 인용한 비율 | `responses_citing_our_domain / total_responses` |
| **가시성–인용률 갭** (Visibility–Citation Gap) | 가시성과 인용률의 차이. 양수일 때 콘텐츠 부재 위험 신호 | `visibility − citation_rate` |

### Tier 2: 통합 인덱스

| 지표 | 의미 |
|---|---|
| **BII** (Bluedot Intelligence Index) | 가시성 + 긍부정 감성 종합 점수, 일 단위 트래킹 |
| **최상단 노출률** (Top Position Share) | 답변 내 가장 처음 위치에 브랜드가 잡히는 비율 |
| **사각지대 점수** | 잡혀야 하는데 안 잡히는 프롬프트 우선순위 (0–100) |

### Tier 3: 분석/리포트

- **상위 인용 콘텐츠** — 어떤 외부 매체/페이지가 AI 답변의 1차 출처로 채택되는지
- **경쟁사 비교 리포트** — 자체 DUCA 프레임워크 (블루닷 내부 명명, 공개되지 않음)
- **프롬프트별 드릴다운** — 답변 원문 + 멘션 하이라이트 + 인용 URL

## 1.6 사용자 여정 (추정)

```
1. 사이트 방문 → "지금 무료 체험" 클릭
2. 회원가입 + 브랜드 기본 정보 입력
   - 브랜드명 / 별칭 / 공식 도메인 / 카테고리 / 경쟁사
3. 시드 키워드 입력 또는 카테고리 기반 자동 프롬프트 생성
   - "프롬프트 추천" 기능이 4단계 고객여정에 따라 자동 생성
4. 24~48시간 첫 스냅샷 대기 (이메일 알림 추정)
5. 대시보드 첫 진입
   - 3 KPI 카드 + BII 트렌드 + 엔진별 요약
6. 인사이트 발견
   - "이 프롬프트는 사각지대다 → 콘텐츠 생성 필요"
7. 블루닷CMS로 원클릭 이동 → 콘텐츠 자동 초안 생성
8. 발행 → 재측정 → BII 상승 확인
```

## 1.7 가격 모델 (추정)

직접 접근 불가로 정확한 가격은 미공개. 그러나:

- 페이지 `bi.bluedot.so/pricing` 존재 확인
- **"프로" 플랜** 명시적 존재 (AI Mode는 프로 한정)
- "지금 무료 체험" CTA로 보아 **카드 미요구 트라이얼** 추정
- 글로벌 비교군:
  - Profound: $99/$399/$499/Enterprise
  - Peec.ai: $89/$199/$499
  - Otterly: $29/.../$989
- 한국 시장 SMB 결제력 감안 시 **₩100K~₩800K/월 + Enterprise 협의** 분포 추정

## 1.8 디자인·브랜드 단서

- **시그니처 컬러**: 회사명 "블루닷(Blue Dot)" → 파랑 계열 도미넌트 추정
- **한글 폰트**: 한국 B2B SaaS 표준이 Pretendard → 동일 추정
- **콘텐츠 톤**: 보도자료·블로그 기준 **B2B 마케터 전문가 톤**, 기술 용어를 비기술자에게 풀어쓴 스타일
- **블로그 운영**: blog.bluedot.so에서 매주 업데이트 / 기능 변경 사항 공개 → 투명한 변화 노출 전략

## 1.11 빠진 정보(Gaps) — 필요 시 추가 조사

- 정확한 가격 (₩ 단위)
- 무료 체험 기간/제약
- 최소 계약 단위
