## 2. 차별화 플레이 (3가지 채택 권장)

### 선택지 비교

| 플레이 | 임팩트 | 구현 비용 | 글로벌 모방 가능성 |

| B. **한국어 NER·감성 분석 정확도** | 높음 | 중 | 낮음 |
| C. Naver/Kakao AI 검색 인덱싱 | 매우 높음 | 낮음 (출시 시) | 낮음 |
| D. CMS·노션·워드프레스 액션 통합 | 높음 | 높음 | 중 |
| E. 에이전시 화이트라벨 | 중 | 낮음 | 높음 |

### **선정: A + B + E** (Korean LLM 커버 + Korean NLP + 에이전시 화이트라벨)

**근거**:
- A·B는 글로벌 도구의 사각지대 = 영구적 모트
- E는 **현금 흐름 가속화** (에이전시 1곳 = SMB 10곳분 ARPU)
- C는 시장 시그널이 나오면 즉시 추가 (옵션 가치)
- D는 Phase 4 이후 — MVP 부담 과대

## 3. MVP 정의 (반드시 포함만)

### 3.1 기능적 MVP

| 항목 | 사양 |
|---|---|
| 모니터링 단위 | 1 브랜드 × 3 엔진 × 100 프롬프트 × 1일 1회 |
| 엔진 | ChatGPT (gpt-4o), Perplexity, Google AI Overviews |
| 프롬프트 생성 | 카테고리 시드 → GPT-4o-mini로 자동 확장 + 사용자 수동 추가 |
| 응답 저장 | 원문 + 인용 URL + 타임스탬프 |

### 3.2 메트릭 MVP

1. **Visibility Score**: 브랜드 멘션률 (전체 응답 중 %)
2. **Citation Rate**: 도메인 인용률
3. **Sentiment**: 긍정/중립/부정 3단 분류
4. **Top Blind Spots**: 멘션되지 않은 high-intent 프롬프트 TOP 10

### 3.3 비기능 MVP

- 온보딩 ≤ 1일 (브랜드명 + 카테고리 → 자동 프롬프트 → 첫 리포트)
- 가격 부담 ≤ $300/mo
- 응답 시간 ≤ P95 3초 (대시보드)
- 데이터 보존 ≥ 90일

### 3.4 MVP에서 **제외**

| 제외 항목 | 사유 |
|---|---|
| YouTube AI 검색 분석 | 데이터 소스 불안정 |
| FAQ 자동 생성 | Phase 4 차별화 자산 |
| Citation Probability Scorer | ML 모델 학습 데이터 부족 |
| 멀티 브랜드 비교 | Phase 2 |
| 경쟁사 BII 인덱스 | Phase 3 |
| Slack/Teams 알림 | 후순위 |

## 4. Build vs Buy 매트릭스

| 컴포넌트 | 옵션 | 권장 | 근거 |
|---|---|---|---|
| **LLM 쿼리 스케줄러** | (a) 자체 큐 + Temporal/BullMQ (b) Apify/ScrapingBee | **자체 큐** (BullMQ + Redis 또는 Celery + Redis) | 핵심 IP, 외부 의존 위험 |
| **ChatGPT/Claude/Gemini 호출** | 공식 API | **공식 API** | ToS 준수, 비용 예측 가능 |
| **Perplexity / Google AIO** | (a) 비공식 스크래핑 (b) SerpAPI Answer Box | **SerpAPI / Serper.dev** ($50/mo부터) | UI 변경 리스크 회피, ToS 보호 |
| **감성 분석 & NER** | (a) GPT-4o-mini judge (b) KoBERT 파인튜닝 | **MVP: gpt-4o-mini judge → Phase 3: KoELECTRA 파인튜닝** | 초기 정확도 80% 즉시 확보 |
| **Domain Authority** | (a) Moz API ($179/mo) (b) Ahrefs ($129/mo) (c) 자체 크롤러 | **유보 (Phase 3)** | MVP 메트릭에 불필요 |
| **SERP 스크래핑** | SerpAPI, DataForSEO, ScrapingBee, 자체 | **DataForSEO** ($50–200/mo) | 가성비 최고, 한국 SERP 안정 |
| **검색 인덱스** | Elasticsearch, Meilisearch, Typesense, Postgres FTS | **Postgres + pgvector** (MVP) → **Typesense** (Phase 3) | 인프라 1개로 시작 |
| **인증** | Clerk, Supabase Auth, NextAuth, 자체 | **Supabase Auth** | DB 통합 즉시, 한국 결제 연동 용이 |
| **결제** | Stripe, TossPayments, 토스 + Stripe 듀얼 | **TossPayments** (국내) + **Stripe** (해외) | 한국 SMB는 카드 결제 선호 |
| **호스팅** | Vercel+Supabase, Railway, AWS, 자체 k8s | **Vercel + Supabase + Upstash** | 솔로/소수 팀 최적 |
| **워커/스케줄러 호스팅** | Vercel Cron, Railway, Fly.io | **Fly.io** ($5–30/mo) | Vercel Cron 한계 우회 |
| **모니터링** | Datadog, Sentry, Axiom | **Sentry + Axiom Logs** | $0–50/mo |
| **데이터 웨어하우스** | BigQuery, Snowflake, ClickHouse | **MVP: Postgres / Phase 2+: ClickHouse Cloud** | 시계열 집계 50× 가속 |

**핵심 원칙**: 코어 IP (스케줄러·메트릭 계산)는 Build, 주변부 (인증·결제·스크래핑)는 Buy.

### 9.2 콘텐츠 마케팅 = 도그푸딩

자사 사이트를 **"GEO 분석 도구로 한국 GEO 1위에 랭킹된 도구"** 포지셔닝.
