# Visual Identity v2 — nedabah.org (2026-09-25 정립)

> 대표님이 보내주신 NEDABAHWAY 브랜드 보드를 로고 원본으로 확정(2026-09-25).
> v1(`visual-identity-v1.md`)의 "코발트 엣지 포인트 전용", "UI 노란색 금지" 규칙은 이 문서로 대체됩니다(사용자 결정: "새 팔레트로 전면 교체").

## 1. 로고

- 원본: 브랜드 보드의 메인 로고(심볼 + `NEDABAHWAY` 워드마크 + `JEJU · EDUCATION · LIFE`)
- 사이트용 파일 (`assets/brand/`, 배경 투명 PNG)
  - `nw-logo.png` — 전체 로고(제안서·인쇄물용)
  - `nw-wordmark-color.png` — 알록달록 워드마크(헤더·푸터·공유 카드). 글자마다 6색 붓 터치가 들어간 NEDABAHWAY로, 두 번째 브랜드 보드(2026-09-25)의 대형 로고를 그대로 오려 씀
  - `nw-symbol.png` — 6색 심볼 + 별표(파비콘·앱 아이콘)
  - `nw-wordmark.png` — 검은 워드마크(단색이 필요할 때, 사이트 헤더에는 쓰지 않음)
- 로고 옆에 한글 "네다바웨이"는 붙이지 않습니다.
- 로고는 보드 그대로 사용하며, 색이나 모양을 다시 그리지 않습니다.

## 6. 사이트 전체 적용 (2026-09-25)

- 공용 CSS(`v3.css`, `warm-tone-v1.css`, `global-nav.css`, `nedabah.bundle.css`, `mobile-v1.css`, `typography-v4.css`, `back-to-top.css`, `deck-toggle.css`)의 색 값을 v2로 바꿨습니다. 변수 이름(`--copper`, `--c-cobalt` 등)은 기존 페이지 호환을 위해 그대로 두었습니다.
- 모든 페이지 헤더(`.gnav__logo`)의 글자 로고를 알록달록 워드마크 이미지로 바꿨고, 페이지를 만드는 빌드 스크립트의 헤더 템플릿도 함께 바꿨습니다.
- 페이지 안에 직접 적은 색(inline style, 페이지별 `<style>`)과 페이지 생성 스크립트의 색도 같은 기준으로 바꿨습니다(보관용 `_archive*` 폴더 제외).
- 종이색 바탕(`#f1ede5`)은 흰색보다 조금 어두워서, 흰 바탕 기준으로 맞춰 두었던 회색 글씨를 한 단계 진하게 바꿨습니다.

## 7. 색 대비 기준

| 용도 | 색 | 종이색 위 대비 |
|---|---|---|
| 본문 | `#1b1b1b` | AAA |
| 보조 글씨 | `#55504a` | AA |
| 흐린 글씨(날짜·출처) | `#665f57`, `#6b655e` | AA |
| 링크·버튼 | `#1D4ED8` | AA |

- 6 TYPES 색(특히 Maker 노랑, Enjoyer 분홍)은 글자색으로 쓰지 않습니다. 면·그림자·아이콘에만 씁니다.
- 어두운 바탕(예: 코칭 페이지 네이비) 위에서는 Maker 노랑을 강조 글씨로 쓸 수 있습니다.
