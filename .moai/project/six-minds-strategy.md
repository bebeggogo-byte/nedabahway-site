# 「6가지 마음」 사이트 구조 전략

작성 2026-09-26 · 기준 문서: 2026-09-25 전략 브리프 「6가지 마음 진단 설계 전략」

## 1. 결정: '6가지 마음'으로 간다 ('6가지 사람'이 아니라)

| 기준 | 6가지 사람 (Explorer는 사람) | 6가지 마음 (Explorer는 마음) |
|---|---|---|
| 브리프의 핵심 원칙 "유형 라벨링 금지, 누구나 여섯을 다 갖고 있다" | 어긋남. "너는 탐험하는 사람"이 곧 라벨 | 맞음. 마음은 여섯 개 다 있고 배분만 다름 |
| 다시 잴 이유 | 없음. 사람은 안 바뀌니 한 번이면 끝 | 있음. 상태는 2주 단위로 바뀌니 4주 뒤 재진단이 자연스러움 |
| 결과의 언어 | "당신은 ○○형" → 판정, 비교, 우열 | "요즘 ○○을 많이 쓰고 △△이 눌려 있다" → 관찰, 조정 |
| 프로그램 연결 | 유형별 코스가 필요해져 6갈래로 쪼개짐 | 상태별 처방(줄일 것·늘릴 것)이라 코스 4개와 그대로 연결 |
| 기관 집계 | 유형 분포표(사람 나누기) | 6마음 평균·총량 변화(사전·사후) → 결과보고서에 맞음 |
| 청소년이 스스로 "맞네"라고 말할 가능성 | 낮음. 라벨은 방어를 부름 | 높음. "이걸 더 하려고 저걸 줄여 왔구나"는 관찰이라 받아들이기 쉬움 |
| 브랜드 캐릭터 6종과의 호환 | 캐릭터=사람이라 유형 굳힘 | 캐릭터=마음의 통로. 첫 화면 띠에서 그대로 씀 |

판단: **마음**. '사람'은 기억하기 쉽지만 브리프가 세운 모든 원칙과 충돌한다. '사람'이라는 말은 캐릭터 이름 뒤에 붙는 별명으로만 남기고(예: "탐험하는 마음 · Explorer"), 진단·해설·프로그램 연결은 전부 '마음'과 '상태'의 언어로 쓴다. 2026-09-26에 첫 화면 띠의 "탐험하는 사람"을 "탐험하는 마음"으로 바꿨다.

## 2. 사이트 구조 (현재 상태 기준)

```
첫 화면 6 MINDS 띠 (아이콘 6개, 클릭)
   └─ /diagnosis/minds/#탐험 … 마음 설명 카드 6개 (정의 · 잘 씀/눌림/넘침 신호)
        └─ 같은 페이지 상단: 「요즘 나의 여섯 마음」 15문항 진단
             └─ 해설지 (①총량 ②배분 ③네 자리 ④알아차림 ⑤이번 주 조정 ⑥총량 키우기 ⑦여섯 마음 하나씩 ⑧4주 비교)
                  └─ 상태별 다음 걸음: 무료 30분 상담 / 학습 습관 코스 / 진로 탐색 코스 / 기관 교육
홈 무료진단 섹션 · /diagnosis/ 선택 화면 3박스 → 같은 진단
```

## 3. 해설지가 답하는 다섯 질문 (다각도 분석 기준)

1. **내 에너지가 이 정도구나** — 총량 링(0~100)과 띠(넉넉·보통·눌림·회복 우선). 총량은 잠·움직임·의욕 60% + 여섯 마음 충전 평균 40%. 잠·움직임·의욕 각각을 칩으로 보여 어디서 새는지 짚는다.
2. **여섯 마음을 모두 받아 본다** — 사용량 순 막대 6개, 색은 충전·고갈·그대로. 쏠림 지수(최고−최저 사용량)로 "한쪽으로 크게 쏠림 / 쏠림 있음 / 고름"을 말한다. ⑦에서 마음 하나마다 상태(잘 쓰고 있음·눌려 있음·넘쳐 있음·보통)와 이번 주 행동 한 줄을 준다.
3. **이쪽을 줄이고 저쪽을 늘려야겠다** — 사용량×충전 네 자리: 엔진(많이·충전) / 과부하(많이·고갈) / 숨은 자원(적게·충전) / 쉬는 통로(적게·고갈). 줄일 것은 과부하 통로, 늘릴 것은 숨은 자원 통로가 1순위. 숨은 자원이 없으면 눌린 것 중 고갈 아닌 것, 그것도 없으면 최저 사용.
4. **이걸 더 하려고 저걸 줄여 왔구나** — 트레이드오프 문장(최고 사용 A vs 최저 사용 B)과 '요즘의 패턴' 한 줄. 여기에 '예리하게 보면' 카드: 고갈 통로가 3개 이상이면 "새는 곳 막기가 먼저", 충전형이 0개면 "성향이 아니라 상태", 잠이 1 이하면 "첫 줄은 잠", 크게 쏠렸는데 충전형이면 "두 번째 통로를 미리 열어 두라".
5. **총량 자체를 어떻게 늘리나** — 네 원칙을 개인화해서: 회복이 먼저(내 충전형 통로 20분) / 고갈형은 방식 바꾸기(내 과부하 통로에 끝낼 것 하나) / 짝지어 쓰기(내 충전형을 내 고갈형 앞뒤에) / 몸이 바닥(가장 낮은 지표부터 한 가지 행동).

그리고 ⑧ 4주 비교: 브라우저에 최근 6회를 남겨, 7일 이상 지난 결과가 있으면 총량 변화와 마음별 ▲▼를 보여 준다. "상태 진단"이라는 취지는 여기서 증명된다.

## 4. 실행 순서

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 15문항·마음별 신호·줄일 것/늘릴 것 문장 확정, 사이트에 구현 | 완료 (2026-09-25~26) |
| 2 | 해설지 8단 구성, 4주 비교 | 완료 (2026-09-26) |
| 3 | 첫 화면 띠 클릭 연결, 무료진단 선택 화면 3박스, 홈 카드 3개 | 완료 |
| 4 | 청소년 10명 종이 시험 → 이해 안 되는 문장 고치기 | 대표 진행. 고칠 문장은 `scripts/build-minds.py`의 MINDS/TOTAL 표만 바꾸면 됨 |
| 5 | 결과 저장·4주 뒤 재진단 메일 | 고민 벽과 같은 Supabase에 표 하나 추가(응답 15개·시각·이메일 선택). 동의 문구와 개인정보처리방침 항목 추가 후 |
| 6 | 마음별 페이지 6개(/minds/explorer …) | 카드 6개가 이미 있으므로, 각 마음의 '늘리는 법·줄이는 법·관련 코스'를 더 쓸 때 분리 |
| 7 | 기관용 집계 | 회기 첫날·마지막 날 같은 진단, 개인 결과는 본인에게, 기관에는 6마음 평균과 총량 변화만. 5단계 저장이 되면 CSV 집계로 시작 |

## 5. 잘 되었는지 보는 기준 (브리프 그대로)

- 진단 완료율 70% 이상, 평균 소요 4분 이내
- 해설지 복사 비율 30% 이상 (저장 기능 전까지는 '복사'가 저장의 대리 지표)
- 4주 뒤 재진단 참여 20% 이상
- 기관 과정 사전·사후 총량 평균 상승
- 해설지에서 상담·코스로 넘어가는 비율

## 6. 지키는 선

- '검사'가 아니라 '상태 보기'. 우울·불안 단어를 쓰지 않는다. 총량 30 미만이면 1388·1393·129 안내를 조용히 붙인다(구현됨).
- "당신은 ○○형"이라고 말하지 않는다. 문장마다 "여섯 개를 다 갖고 있다"는 전제를 지킨다.
- 첫 화면 캐릭터 아래 이름은 "○○하는 마음"으로 통일한다. 브랜드 보드의 "○○하는 사람"은 캐릭터 소개용 별명으로만 남긴다.
