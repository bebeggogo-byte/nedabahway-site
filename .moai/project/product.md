# product.md — nedabah.org

## 1. 제품 정의

**nedabah.org**는 김창환 강사(네다바웨이)의 강의·교육·코칭 사업을 위한 **공개 사이트 + 자료실 + 매거진 통합 플랫폼**이다.

> 한 줄 정의: "강의 의뢰자가 신뢰를 두께로 보고, 학습자가 쓰는 자료를 한 장씩 가져갈 수 있는 결."

## 2. 누가 쓰는가 (3계층 사용자)

### 2.1 외부 사용자 (Public)
| 사용자 | 결 | 핵심 욕구 |
|---|---|---|
| **강의 의뢰 잠재 고객** | 기관 담당자·교사·HR | "이 강사 진짜 신뢰할 만한가" 즉시 확인 |
| **자료 검색자** | 직장인·교육자·학생 | 활동지·진단도구·프롬프트팩 즉시 다운로드 |
| **매거진 구독자** | 일·진로·관계 글에 관심 있는 일반인 | 1만 편 관점 노트로 결 잡기 |

### 2.2 반공개 사용자 (Showcase)
- 신뢰를 보여줄 외부인 (분기 운영 요약·익명화 사례)

### 2.3 비공개 사용자 (Private)
- CEO 본인 (Daily Intel·KPI 원장·클라이언트명·계약 — 사이트 게시 절대 금지)

## 3. 왜 만드는가 (핵심 가치)

1. **강의 의뢰 자동 흐름** — 책보다 살아 있는 글 100~10,000편이 결정적
2. **달란트 전파** — 사회가 필요로 하는 곳에 자료·관점 무료 배포
3. **신뢰의 두께** — 1편 시작·5편 검증·20편 정착·100편 가늠·10,000편 도착
4. **사용자 자기 결핍 인식** — 글·진단도구로 "한 사람의 결핍" 결 발견
5. **수익 사다리 5단계** — 무료 자료 → 유료 워크북 → 1on1 코칭 → 그룹 워크숍 → 기관 강의

## 5. 운영 원칙

### 5.1 3계층 분리 (절대 혼용 금지)
- **public** : 외부 마스터 카드 + sitemap + 외부 feed
- **internal**: CEO 콘솔(`_console/`)에서만 보임 (로컬 127.0.0.1:8765)
- **draft** : 어디에도 안 보임

### 5.2 SSoT (Single Source of Truth)
- `resources/_data/feed.json` = 모든 자료 메타의 단일 진실 원천
- `_build/render_all.py` 1회 호출 = 마스터·콘솔·changelog·sitemap·feed 자동 재생성
- 인덱스 페이지 수동 편집 영구 금지

### 5.3 자동 게시 흐름
- D1~D25 부서가 자료 생성 → publisher가 분류(public/showcase/private) → 자료실 게시
- 비공개 키워드(클라이언트명·금액·계약 등) 자동 차단
- LaunchAgent: `com.nedabah.agent.site_publisher` (1시간 주기 catch-up)

## 6. 외부영향 7종 (HAG 승인 필요)
