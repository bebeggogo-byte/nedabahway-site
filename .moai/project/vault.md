# 비공개 자료실 (vault) 운영 안내

2026-09-25 개편으로 공개 사이트는 새 페이지 5개(홈·소개·프로그램·도구·문의)와 미니 도구 12개, 개인정보처리방침, 404, 오프라인 페이지만 남았습니다. 개편 전 페이지 약 15,000개는 비밀번호로 잠긴 `/locked/` 자료실로 옮겨졌습니다.

## 어떻게 잠겨 있나

- 잠긴 페이지 파일에는 원문 대신 암호화된 내용만 들어 있습니다. `assets/vault.js`가 브라우저에서 비밀번호로 열쇠를 만들어 풀어 보여 줍니다.
- 비밀번호는 저장소 어디에도 적혀 있지 않습니다. 저장소에 있는 것은 소금값(`SALT`)과 암호문뿐입니다.
- "이 기기에서 기억하기"를 켜면 만들어진 열쇠가 그 브라우저에만 저장돼, 다음 페이지부터 바로 열립니다. `/locked/`의 "이 기기에서 잠그기" 버튼으로 지웁니다.
- 잠긴 페이지는 검색엔진 색인에서 제외(`noindex`)되고, `robots.txt`와 `sitemap.xml`에도 공개 페이지만 남아 있습니다.

## 한계 (알고 쓰기)

- HTML 페이지만 잠깁니다. PDF(`magazine/_pdf/`), 이미지, JSON 데이터 파일은 주소를 알면 그대로 열립니다.
- 저장소가 공개 저장소라면 과거 커밋 기록에 개편 전 원문이 남아 있습니다. 완전히 감추려면 저장소를 비공개로 바꾸거나 기록을 정리해야 합니다.
- 비밀번호를 잊으면 잠긴 페이지는 이 도구로 풀 수 없습니다. 개편 전 원문은 git 기록(커밋 `561ed455` 이전)에서 다시 꺼낼 수 있습니다.

## 명령

```
node scripts/vault.mjs list                          # 잠글 대상 확인
VAULT_PASSWORD=... node scripts/vault.mjs encrypt    # 아직 안 잠긴 페이지를 잠금
VAULT_PASSWORD=... node scripts/vault.mjs decrypt    # 로컬에서 원문으로 되돌림(편집용)
```

- 공개 페이지 목록: `scripts/vault-public.txt`. 여기 없는 `.html`은 모두 잠급니다.
- 자료실 페이지를 다시 생성하는 빌드(`resources/_build/render_all.py`, `_build/apply_global_nav.py` 등)를 돌린 뒤에는 반드시 `encrypt`를 다시 실행해야 합니다. 안 하면 그 페이지가 원문 그대로 공개됩니다.
- 원문을 고치려면 `decrypt` → 편집 → `encrypt` 순서로 합니다. 되돌린 원문을 커밋하지 않도록 주의합니다.
- 비밀번호를 바꾸려면 `decrypt`(옛 비밀번호) 뒤 `encrypt`(새 비밀번호)를 실행합니다.
