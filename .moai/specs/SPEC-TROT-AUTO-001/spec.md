## 1. Background

Public case study (`현장속으로` channel) demonstrates a one-person, AI-driven content factory targeting the Korean 50-70 senior demographic via trot music news/highlights. Reported figures: 9 YouTube channels, ~200 daily pieces of content, ~₩30M monthly net revenue, 2h daily operator workload, ₩16.8T addressable market.

This SPEC defines the MoAI implementation of a similar but **legally hardened, post-2026 entrant** version. It explicitly substitutes high-risk inputs (copyrighted trot audio, real artist photography, scraped news articles) with safer derivatives (AI-generated BGM, AI illustrations, original commentary on public-domain facts).

## 2. Goal (EARS)

WHILE the operator runs at most 2 hours of supervision per day,
WHEN the system receives a curated list of trot domain news/events,
THE Trot Content Automation Factory SHALL produce, schedule, and publish at least **5 YouTube Shorts per day** to a single channel, achieving YouTube monetization eligibility (1000 subscribers + 4000 watch-hours OR 1000 subs + 10M Shorts views over 90 days) within **6 months of first publish**.

## 3. Scope

### 3.1 In-Scope (Phase 1 MVP)

- Single YouTube Shorts channel, Korean-language, trot-genre focus.
- Self-hosted n8n on Oracle Cloud Free Tier (or sub-₩50,000/mo VPS) as orchestration backbone.
- Source ingestion via Naver News API + public RSS feeds + chart APIs (Melon, Bugs public data).
- AI script generation via Anthropic Claude API (`claude-sonnet-4-6` default; `claude-haiku-4-5` for cost-sensitive variants).
- TTS via Edge TTS (free) primary, ElevenLabs (paid, optional voice clone of operator) secondary.
- Imagery via Pollinations (free) or Stability AI (paid) — **AI-generated illustrations only, never real artist photos**.
- BGM via Suno or Udio API — **all music generated by operator account, royalty-free outputs**.
- Video composition via FFmpeg locally (free) with Creatomate as paid fallback.
- YouTube upload via YouTube Data API v3 (OAuth2).
- Metadata catalog in Notion (free tier).

### 3.2 Out-of-Scope (deferred to Phase 2+)

- Multi-channel replication (only after Phase 1 channel monetizes).
- Naver Blog, Instagram, TikTok cross-posting (Phase 2).
- News portal registration (`인터넷 신문사`) (Phase 3 — legal/business review required).
- Live commerce, super-chat, membership pricing (Phase 4).
- K-Trot mobile app platform (Phase 5, multi-year horizon).
- Education/course sales (Phase 6, requires proven track record first).

### 3.3 Explicit Non-Goals (Permanent)

- Direct reuse of copyrighted trot recordings.
- Use of real trot artists' photographs without licensing.
- Verbatim or near-verbatim rewriting of news articles (Korean Press Foundation guidelines).
- Defamatory commentary on living artists.
- Astroturfing, fake engagement, view-buying.

## 4. Requirements (EARS Format)

### REQ-INGEST-001 (News Curation)

WHEN the scheduler fires at the configured cron interval (default: every 4 hours),
THE system SHALL ingest the latest trot-related news items from Naver News API and configured RSS feeds, deduplicate by canonical URL hash, and store new items in the `raw_news` Notion database with status `pending`.

### REQ-INGEST-002 (Source Diversity)

WHILE the system selects items for content generation,
THE system SHALL NOT use more than 40% of items in any 7-day window from a single source domain, to reduce derivative-content risk and improve coverage.

### REQ-FILTER-001 (Quality Filter)

WHEN a `raw_news` item enters the pipeline,
THE system SHALL run an LLM classification pass to assign genre confidence (0.0-1.0) and topical tags, and only items with confidence >= 0.75 SHALL proceed to script generation.

### REQ-SCRIPT-001 (Script Generation)

WHEN a filtered news item enters the script-generation node,
THE system SHALL produce an original 30-60 second Shorts script in Korean comprising:
(a) a hook (3-5s), (b) factual summary (10-20s, citing public facts only), (c) operator-voice commentary (10-25s, generated angle), (d) CTA (3-5s).
The script SHALL be tagged with the source URL but SHALL NOT reuse more than 20 contiguous characters from the source.

### REQ-VOICE-001 (TTS)

WHEN a script is approved by the autonomous quality gate (LLM rubric scoring >= 0.70),
THE system SHALL synthesize voice audio via the configured TTS provider with the operator-selected Korean female narrator voice profile, normalized to -16 LUFS.

### REQ-VISUAL-001 (Imagery)

WHILE assembling visual assets for a Short,
THE system SHALL generate 3-6 AI illustrations per video using neutral prompts (NO real-person likenesses, NO trademarked elements), and SHALL include a watermark "AI 생성 일러스트" on the final video.

### REQ-MUSIC-001 (BGM)

WHILE the operator account holds Suno/Udio output rights,
THE system SHALL use only BGM tracks generated under the operator account, indexed in the `bgm_library` Notion database, with `usage_count` and `last_used_at` rotation logic preventing the same track from appearing in more than 2 consecutive uploads.

### REQ-COMPOSE-001 (Video Composition)

WHEN audio, imagery, and BGM are ready,
THE system SHALL compose a 1080x1920 vertical Short using FFmpeg with the configured template (intro 2s, body, outro 2s), embed open captions (Whisper-aligned), and burn-in the AI-disclosure watermark.

### REQ-PUBLISH-001 (YouTube Upload)

WHEN a composed video passes the autonomous final checks (duration 15-60s, captions present, watermark detected),
THE system SHALL upload to YouTube via Data API v3 with operator-configured defaults (category 10 Music, language ko, kids: false) and queue at the next available slot in the operator's publishing schedule (default: 5/day at 07:00, 10:00, 13:00, 17:00, 21:00 KST).

### REQ-PUBLISH-002 (Disclosure)

WHILE uploading,
THE system SHALL prepend "[AI 자동 제작]" to the description and add hashtags `#AI트로트` `#AI생성` and the YouTube `altered_content` flag set to `synthetic`.

### REQ-LOG-001 (Audit Trail)

WHEN any pipeline step completes,
THE system SHALL append a row to the `pipeline_runs` Notion database including timestamp, video_id, source_url, model versions used, cost in USD, and a SHA256 of the script.

### REQ-COST-001 (Budget Guard)

IF the rolling 30-day API cost exceeds ₩450,000 (90% of ₩500,000 budget),
THE system SHALL halt new generation and notify the operator via the configured Telegram/Discord webhook.

### REQ-LEGAL-001 (Takedown Channel)

WHILE the channel is active,
THE operator SHALL maintain a public takedown contact email on the YouTube channel `About` page, and the system SHALL keep deletion turnaround under 24 hours on operator command via the `takedown` n8n workflow.

### REQ-EVAL-001 (Performance Feedback)

WHEN a video reaches 48 hours since publish,
THE system SHALL pull YouTube Analytics (views, average view duration, retention %, CTR) into the `performance` Notion database, and SHALL re-train the script-generation prompt monthly on the top decile and bottom decile by retention.

## 6. Non-Functional Requirements

- **Availability**: pipeline tolerates single source outage (graceful skip + log).
- **Observability**: every n8n execution writes to Notion + a structured JSON log file rotated daily.
- **Security**: all API keys stored in n8n credential store; no secrets in workflow JSON or git.
- **Reproducibility**: `docker-compose up` from a fresh VPS produces a working pipeline within 30 minutes (assumes credentials configured).
- **Portability**: pipeline workflows export-importable as JSON; no proprietary lock-in beyond n8n itself.

## 7. Risk Register

| ID | Risk | Severity | Mitigation |
|----|------|----------|------------|
| R-1 | Copyright strike from trot music labels | CRITICAL | No copyrighted music; only operator-generated BGM; AI-art watermark; takedown channel |
| R-2 | Right-of-publicity claim from trot artist | HIGH | No real photos; AI illustrations are stylized non-likeness; commentary on facts only |
| R-3 | News portal copyright (한국언론진흥재단) | HIGH | Original commentary only; <20 char overlap with source; source link credit |
| R-4 | YouTube AI-content policy demonetization | MEDIUM | `altered_content=synthetic` flag set; AI disclosure in title/description |
| R-5 | API cost runaway | MEDIUM | REQ-COST-001 budget guard halts at 90% |
| R-6 | TTS voice clone misuse claim | LOW | Use stock TTS voices only in Phase 1; defer voice cloning to Phase 2 with clear operator consent |
| R-7 | Late-mover saturation in trot niche | MEDIUM | Differentiation: AI-illustration aesthetic, fact+commentary angle, BGM uniqueness |
| R-8 | Operator burnout despite automation | LOW | <=2h/day target enforced; weekly off-day scripted into schedule |

## 8. Phase Plan (high level — full plan in `plan.md`)

- **Phase 4 — Monetization (Months 4-6)**: hit YPP eligibility, enable ads.
- **Phase 5 — Replication (Month 7+)**: clone channel template after Phase 1 channel monetizes.
