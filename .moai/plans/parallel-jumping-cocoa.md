# 계획: ME → WE 워크숍 활동지 — 크리스찬 버전

## Context (배경)

`workbook/me-we/index.html`은 셀프리더십·코칭·팀빌딩 세속 워크숍 활동지(단일 HTML 웹앱)로 이미
사이트에 배포되어 있다. 사용자는 이것의 **크리스찬 버전**을 원한다. 결정된 방향:

- **각색 깊이**: (1) 각 섹션에 성경 구절·묵상·기도 요소를 더하고, **동시에** (2) 밑바탕 이론을 신앙 관점으로 재구성한다.
- **위치**: 기존 세속 버전은 그대로 두고 **새 페이지**로 추가한다.
- **성경 번역**: 개역개정(본문) + 새번역·NIV(보조) + 원어(헬라어/히브리어) 핵심어 레이어.
- **신학 톤**: 초교파 복음주의 일반 + 성경 중심(교리 논쟁 최소) + 네다바웨이(자원하는 헌신) 정체성 — 셋을 균형 있게.

nedabah.org는 신앙 기반 단체(네다바웨이 = 히브리어 נְדָבָה, 자원하는 예물/freewill offering, 출 35)이며,
지금까지 **인터랙티브 워크지는 전부 세속**이고 **신앙 콘텐츠(SBM/magazine)는 전부 읽기용 관찰**이었다.
이 둘을 처음으로 결합하는 새 산출물이다.

---

## 접근 요약

`workbook/me-we/index.html`을 **구조·인터랙션 로직 그대로 복제**한 새 파일을 만들고, **콘텐츠 레이어만**
신앙 버전으로 교체·증강한다. 진단 문항·차트·상태저장·PDF 리포트 등 **검증된 메커니즘은 유지**하고,
각 섹션에 (a) 이론의 신학적 재프레이밍, (b) 성경 구절 블록, (c) 짧은 묵상/기도 항목을 더한다.
과잉설계 금지 — 새 프레임워크를 발명하지 않고 기존 흐름 위에 신앙 레이어를 얹는다.

**대상 사용자**: 교회 소그룹·직장 신우회·기독 자활/일터 공동체. SBM 정신을 따라
"가르침이 아닌 관찰·자기성찰"로, 신앙 배경이 옅어도 부담 없이 참여 가능하게.

## 파일 & 배포

- **새 파일**: `workbook/me-we-faith/index.html` (단일 자기완결 파일 — `me-we`와 동일한 self-contained 모델)
  - 라이브 예정 주소: `https://www.nedabah.org/workbook/me-we-faith/`
  - *페이지 제목/URL 슬러그는 승인 시 조정 가능* (예: `me-we-faith`, `me-we-shalom`, `nedavah-workshop` 등).
- **localStorage 키 네임스페이스 분리**: `mewe_` → `meweF_` (기존 세속 버전과 응답이 섞이지 않게). remember 키도 `meweF_remember`.
- **배포**: 기존과 동일 — GitHub Pages(`.github/workflows/pages-deploy.yml`), `main` push 시 자동.
  `workbook/`는 배포에 포함됨.
- **링크 전용(비색인) 유지**: `sitemap.xml` / `.moai/specs/SPEC-DISCOVERY-001/public-pages.txt` **건드리지 않는다**

  glossary.html offline.html p/*.html`)도 아니므로 CI 영향 없음.
- **핸드오프 문서**: 완성 후 `workbook/me-we-faith/README.md`도 추가(기존 `me-we/README.md` 패턴) — 새 채팅 이어작업용.

## 구현 순서 (승인 후)

MoAI 위임: 콘텐츠(성경·신학 카피)는 `moai-domain-copywriting` 관점, 구현은 `expert-frontend`.
단일 파일이라 순차 진행:

1. `workbook/me-we/index.html` → `workbook/me-we-faith/index.html` 복제.
2. 색 토큰(CSS `:root`)을 브랜드 코발트/세이지/종이톤으로 교체, Noto Serif KR 인용 스타일 추가.
3. 상태 키 프리픽스 `mewe_`→`meweF_` 일괄 변경(로그인·remember·save 포함).
4. 섹션별로 위 매핑대로 이론 텍스트·배너·가이드 카피 신앙 버전으로 교체.
5. 성경 구절 블록 + 접이식 묵상/기도 입력칸 컴포넌트 추가(각 섹션), localStorage·리포트 연동.
6. 로그인/헤더/푸터/리포트 카피 신앙 톤 반영, 대표 구절 배너.
7. 성경 본문 정확성 검증(magazine/ 개역개정 참조), 원어 표기 검증.
8. `workbook/me-we-faith/README.md` 핸드오프 문서 작성.
9. 브랜치 커밋 → 드래프트 PR → CI 확인 → (사용자 승인 시) `main` 병합·배포.

# 추가 작업: HEXACO 성품 진단 섹션 (me-we-faith 3부)

## Context
사용자가 ME→WE **크리스찬 워크지**(`workbook/me-we-faith/index.html`)에 HEXACO 성격검사를 추가하려 함.
- **위치**: 3부(WE), **소통(DiSC, `actDisc`) 섹션 바로 앞**.
- **문항**: 저작권 이슈 회피 필수 → 정식 HEXACO-PI-R 대신 **6요인·facet 구조만 차용한 오리지널 자작 문항**.
- **결과 분석**: **PDF 약 2장 분량**의 상세 리포트.
- **실사용 목적** → 심리측정적으로 성실하게(**허위 규준/백분위 금지**).
- **대상 가정**: 크리스찬 버전 `me-we-faith` 단독. (세속 `me-we`에도 필요하면 이후 미러링 — 승인 시 확정.)

## 삽입 지점 & 라벨
- 새 섹션 id **`actHexaco`**, `actListen`(3-나 경청, 파일 line 570~587)과 `actDisc`(3-다 소통, line 589~) 사이.
- 라벨은 기존 **"1-가+"(파급효과)** 관례를 따라 **"3-나+ · 성품의 여섯 빛깔 (HEXACO)"** → 뒤 섹션 번호 재정렬 불필요.

## 문항 설계 (오리지널, 저작권 free)
- **6요인 × 4문항 = 24문항**, 5점 리커트. 기존 `renderLikert(containerId, prefix, items, onChange)`(line 827) 재사용.
- 요인 정의(자작 문항 근거):
  - **H 정직-겸손**: 진실·공정·비탐욕·겸손 · **E 정서성**: 불안·민감·정서적 의존·공감 · **X 외향성**: 사회적 활력·자신감
