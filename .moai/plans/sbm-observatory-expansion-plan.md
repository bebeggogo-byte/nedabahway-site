### 4.2 생산 파이프라인 (검증된 방식)

```
입력: 골든 예시(GEN/1) + personas.json + sbm-method-spec.md + 대상 장 placeholder
  → 에이전트(general-purpose) 병렬 (동시 6, 에이전트당 2~3장)
  → 각 장 자가검증(§5 체크리스트) + htmlhint
  → 오케스트레이터 커밋·푸시 (장/배치 단위)
  → 블록 완성 시: 책 인덱스 --done 갱신 + sbm-progress 동기화
```

실측: 본 세션에서 동시 6 에이전트로 95장을 생산(장당 ~800줄, htmlhint 0오류). API 오류 1건은 placeholder 복원 후 재투입으로 회복. → **동시 6, 장당 검증, 배치 커밋**이 안정 운영점.
