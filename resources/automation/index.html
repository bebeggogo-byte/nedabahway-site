조직 자동화 9선 — 자료 허브

기획·HR·마케팅 자동화 9가지를 누구나 30분에 만들 수 있도록 정리했습니다. 모든 가이드에는 완성 코드, 시트 템플릿 사양, 트러블슈팅, 응용 아이디어가 포함되어 있습니다. 강의 페이지로 →

공통 스택 (월 0원)

Google Apps Script · Sheets / Docs / Forms / Calendar · Gmail · Gemini 2.5 Flash 무료 티어 (15 RPM) · Slack Webhook/Bot. 코딩 경험 없이 복사·붙여넣기만으로 동작합니다.

📋 기획 자동화 (3선)

PLAN-01

회의록 → 액션아이템 자동 정리

Google Doc 한 장을 던지면 AI가 결정사항·할일·담당자·기한을 추출해 시트에 적재하고 Slack으로 발송합니다. 주 1회 회의 기준 연 130시간 절감.

PLAN-02

경쟁사·뉴스 일일 다이제스트

매일 새벽 RSS와 키워드를 자동 수집하고 AI가 중복 제거·요약해 메일/Slack으로 한 장 다이제스트를 보냅니다. 키워드는 시트 한 줄로 추가/수정.

PLAN-03

주간 KPI 자동 리포트

흩어진 KPI를 매주 월요일 새벽에 모아 AI가 변동·이상 지표 코멘트와 다음 주 권고를 작성한 한 장 리포트로 임원진에 발송.

👥 HR 자동화 (3선)

HR-01

신규 입사자 온보딩 키트

인사담당자가 시트에 합격자 한 줄을 넣으면 환영 메일·90일 체크리스트·1on1 캘린더·Slack 공지가 자동으로 생성됩니다.

HR-02

휴가 신청 슬랙 승인 워크플로우

구글 폼 → 팀장 Slack 승인 카드 → 캘린더·연차 잔여 시트 자동 갱신. 신청부터 승인까지 평균 30분.

HR-03

분기 펄스서베이 + AI 감성 분석

익명 설문 1,000건도 30분 안에 감성·주제·위험 신호 분류. 식별 정보는 AI에 전달되지 않도록 설계되어 있습니다.

📣 마케팅 자동화 (3선)

MKT-01

30일 콘텐츠 캘린더 자동 생성

월 테마 한 줄 → 30일치 채널별 헤드라인·후크·CTA·해시태그까지 시트에 한 번에 채워 넣습니다. 행 단위 재생성도 1클릭.

MKT-02

인입 리드 자동 스코어링·배정

문의 폼이 들어오면 룰 60% + AI 40%로 0~100점 산정해 Hot/Warm/Cold 등급별 담당자 Slack에 카드 발송. 응답 시간 단축이 전환율을 좌우합니다.

MKT-03

리뷰·멘션 주간 다이제스트

네이버 블로그·카페·뉴스 멘션을 매일 자동 수집하고, 부정 멘션은 24시간 안에 즉시 알림. 매주 월요일 1페이지 리포트.

🛠 시작 순서

  1. 가장 자주 잃어버리는 시간을 고르세요. 9개 중 1개부터 시작합니다.
  2. 해당 가이드의 "셋업 가이드"를 따라 30분 작업. Apps Script 속성에 키만 등록하면 동작합니다.
  3. 1주일 운영하며 결과를 본 뒤, 동료에게 가이드 링크를 공유합니다. 두 번째 자동화는 절반의 시간으로 만들어집니다.

⚠️ 안전·윤리 기본선

  • 익명 설문·VOC 분석에서는 식별 정보(이름·이메일·부서)를 AI에 전송하지 않는다.
  • 자동 응답·자동 발송은 사람 검토 단계를 한 번 이상 둔다.
  • API 키는 코드에 직접 쓰지 않고 Apps Script 스크립트 속성에 저장한다.
  • 외부 발송 자동화에는 "보낸 후 되돌릴 수 없는 행위"임을 인지하고 첫 운영 시 강사·담당자가 함께 확인한다.
